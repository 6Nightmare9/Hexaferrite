# Структура и Ms0 (hexw.structures, hexw.params.occupancy, hexw.params.moments)

Этап 4A: ансамбль катионных распределений SrFe(18-x)A(x)O27 (A = Co, Zn, Mn, Mg, Ni и смеси) и намагниченность насыщения
при 0 K. Только fit-литература (`literature/fit`, через `hexw.params.literature`) и физика. Holdout
и vault недоступны коду (`hexw.io.paths`); модуль при импорте не создаёт Pool, не читает данные и не считает подгонку
(подгонка — по первому обращению, `occupancy.default_fit()`, ~15 с, кэшируется).

Модули: `structures/sites.py` (позиции W1–W7), `params/occupancy.py` (модель и подгонка), `structures/ensemble.py`
(кандидаты), `structures/configs.py` (упорядоченные конфигурации для DFT), `params/moments.py` (Ms0).

## 1. Модель предпочтения позиций

Решёточный газ с Fe как опорным сортом, «замороженный» при T_f:

p[s,i] = w[s,i] / (1 + Σ_s' w[s',i]),  w[s,i] = exp(m_s − d[s,i]),  d[s,i] = (ε[s,i] − ε[s,W3]) / (k T_f)

p[s,i] — доля позиции i, занятая сортом s; остаток — Fe. Сдвиг m_s **не параметр**: он решается для каждого состава из
`Σ_i N_i p[s,i] = n_s` (N_i = 2,2,3,2,6,2,1 на ф.е.), т.е. множитель Лагранжа (метод Ньютона по ln n с точным
якобианом, `solve_site_fractions`). Поэтому вместимость (Σ_s p ≤ 1) и содержание A выполняются точно, для любой смеси.
Подгоняются только безразмерные d (6 на сорт, опорная позиция W3).

* **Веса описывают распределение, замороженное при синтезе/закалке (T_f), а не равновесное при температуре измерения.**
* T_f и ε по отдельности вырождены (в любое предсказание входит только d = ε/kT_f). T_f — явный параметр
  `occ_T_freeze`: 1100 K, интервал 400…1523 K (верхняя граница — максимальная температура прокалки в L02-003/-005/-007),
  `identifiable=False`, `status=assumption`. Перевод в эВ: `occupancy.energy_eV(d, T_f)`.
* Допущение модели: d не зависит от состава x. Проверка внутри fit: смесь Co+Zn (L02) предсказывается по чистым Co и Zn
  (тест `test_cozn_is_predicted_from_the_pure_samples`): Co на 6g и Zn на 4e — в пределах 1.5σ; худшее отклонение —
  Zn на W2 (наблюдается 0.100(8), смесь предсказывается заметно ниже; числа — в тесте).

## 2. Данные, подгонка, интервалы, число параметров

Наблюдения (записи `site_occupancy_*`, пересчёт Cmcm-подпозиций L02 6g = 8d+4b, 12k = 16h+8f с весами по кратности
воспроизводит выведенные записи L02-098/-099/-100):

| образец | источник | сорт | позиции |
|---|---|---|---|
| SrCo2W | L02 | Co | W1…W7 |
| SrZn2W | L02 | Zn | W1…W7 |
| SrCoZnW | L02 | Co, Zn | W1…W7 |
| SrMg2W | L01 (fit) | Mg | W1…W6 |
| SrNi2W | L01 (fit) | Ni | W1…W6 |

* σ_eff² = σ_CIF² + σ_sys². **σ_sys — параметр с приором U(0.01, 0.03)** (допущение: стандартные неопределённости Ритвельда —
  не систематические ошибки; `occ_sigma_sys`, роль `assumption`): он **маргинализуется** — каждая из бутстрэп-реплик берёт своё σ_sys,
  разыгрывает с ним наблюдения и перефитовывает с ним (центральное значение 0.02 — только для точечной подгонки и остатков).
* Взвешенный МНК по долям (`scipy.optimize.least_squares`, границы logit ∈ [−9, 9]); у образца-смеси сдвиги m_s решаются из
  содержания в образце. Интервалы — параметрический бутстрэп (**N = 300** пересчётов подгонки с наблюдениями
  p* = p + σ_eff(σ_sys*)·ξ), тот же ансамбль идёт в кандидаты и в Ms0.
* **Co на W3 (6g): единственный источник - L02; перекрёстной проверки в fit нет** (опорная позиция d = 0 для Co задана
  только одним образцом-источником).
* **Число параметров.** Подгоняется 26 логитов (Co 7, Zn 7, Mg 6, Ni 6) на 40 измерений долей, dof = 14, χ² = 6.5 при σ_sys = 0.02.
  **Идентифицируемы устойчиво — во всём диапазоне σ_sys (0.01…0.03) — только 6 относительных энергий d из 10, идентифицируемых при
  σ_sys = 0.01** (позиция идентифицируема, если доля в опорном образце ≥ 3σ_eff; «устойчиво» — это условие при σ_sys = 0.03; потеряны при
  росте σ_sys: Co на W1, Zn на W6, Mg на W1, Ni на W5). Остальные — только нижние границы d (верхние пределы доли),
  `identifiable=False`, широкий интервал [d_нижн, d_нижн + max(8, d_нижн)], `inequality='ge'`. Модель почти насыщена (сорт в чистом образце определяется
  собственными 6–7 числами): предсказательная проверка — только смесь Co+Zn (выше). Дополнительной структуры между
  сортами (напр. «координационный класс») не накладывается: данных для неё нет.

### Mn (нет данных в fit)

В fit для Mn есть только L11 (BaMn2W, tier 3, перенос Ba→Sr не обоснован; заселённостей нет; допущенные авторами моменты
Mn помечены «не использовать»). Приор — из общих соображений, `assumption`, `identifiable=False`, широкий интервал:

у Co/Zn (A на W7 в fit не найден ни разу). Никаких «литературных» чисел для Mn нет; вес гипотез помечается
«вес не определён литературой Sr-W».

## 3. Валентность и вместимость

Электронейтральность (Sr²⁺, O27, Fe²⁺/Fe³⁺, A^q+): n(Fe²⁺) = 2 − Σ_{A²⁺} x_A, n(Fe³⁺) = 18 − x − n(Fe²⁺).
Для A²⁺ это модель ТЗ §7: n(Fe²⁺) = 2 − x, n(Fe³⁺) = 16. Только x ≤ 2 (`ModelNotApplicableError` при x > 2).
Проверка: `hexw.chem.validators` (`check_site_occupancy`, `check_charge_neutral`), `ensemble.check_candidate` для каждого
кандидата. Все 18 позиций заполнены (Fe + A = 18, как в CIF L02).

Mn — альтернативные гипотезы, каждая отдельным кандидатом:
* Mn²⁺ (стандартная): n(Fe²⁺) = 2 − x;
* Mn³⁺: компенсация дополнительным Fe²⁺, n(Fe²⁺) = 2 − x_{A²⁺} (для чистого Mn: 2), n(Fe³⁺) = 16 − x.
Приор 0.5/0.5, метка «вес не определён литературой Sr-W» (в `weight_basis` и `ambiguity` каждого члена).

Fe²⁺ по позициям fit не определяет (везде Fe³⁺; L03/C004 упоминают «6g и/или 4f3», т.е. по site_notation W3 и/или W4 —
вывод по подписи рисунка, не проверен). Три сценария (допущение о наборе): `uniform` (по всем позициям Fe пропорционально), `oct_S_up` (W3, W4), `oct_R` (W5, W6).
**Веса сценариев — не 1/3, а по совместимости с DFT-моментом L05** (L05-093: 54.991 μB на ячейку = 27.50 μB/ф.е., 0 K): гауссово
правдоподобие моментов Гортера сценариев (аналитически 29.33 / 28.00 / 29.00 μB/ф.е.) с σ = 1 μB/ф.е. (допущение: охватывает различие
«сумма по сферам / полный момент»; это оценка по DFT из литературы, не измерение). Результат: **oct_S_up 0.63, oct_R 0.23, uniform 0.13**;
provenance веса — L05-093 (`weight_basis`), сами сценарии остаются допущением.

## 4. Кандидаты (`ensemble.build_ensemble`)

`build_ensemble(composition, hypothesis=None) → StructureEnsemble`: члены = (валентная гипотеза) × (сценарий Fe²⁺).
Каждый член: `StructureCandidate` со средними заселённостями W1–W7 (доли позиции, виды `Co`/`Zn`/…, `Fe3+`, `Fe2+`;
`multiplicity` — для гексагональной ячейки Z = 2), `weight`, `weight_basis`, диапазоны 5–95 % по бутстрэп-ансамблю
(`ranges`), причины неоднозначности (`ambiguity`). Средний кандидат помечен `partial_occupancy_cif_not_dft_config=True`
(`require_dft_configuration()` бросает `PartialOccupancyError`). Причины неоднозначности включают: близкую к насыщению
подгонку, неидентифицируемые позиции (только верхние пределы), отсутствие данных Mn, нелокализованный Fe²⁺, то, что Co на W3 (6g)
опирается на единственный источник - L02 (перекрёстной проверки в fit нет), то, что уточнённое содержание A в образцах fit ниже номинала (Co 1.71, Zn 1.80, Mg
1.69 из 2): ансамбль строится для номинального x.

## 5. Упорядоченные конфигурации для DFT (`configs.generate_configurations`)

* Геометрия — только из CIF L02 `SrZn2Fe16O27.cif` (P6₃/mmc, 300 K); CIF L01 — holdout и не читаются. Расщеплённая
  пара 4f позиции W7 (0.33 Å) заменена точкой 2d на плоскости зеркала (сдвиг 0.16 Å). Ячейка 92 атома (Z = 2); при
  непелом числе атомов — `ConfigError` с требованием суперячейки (`supercell=(a,b,c)`).
* Целые числа атомов A по типам позиций — из ансамбля (по одной квотизации «наибольший остаток» на бутстрэп-повтор,
  вместимость соблюдается); частота вектора чисел = его вес.
* Все размещения на 36 позициях сворачиваются в симметрийно неэквивалентные группой P6₃/mmc (24 операции, spglib через
  pymatgen); вес орбиты = (число размещений орбиты / все размещения) × вес вектора (идеальное смешение внутри вектора).
* Возвращается `n_rep` ∈ [2, 5] лучших орбит, веса перенормированы, `coverage` — доля вероятности, покрытая ими.
* Fe²⁺: размещение «наиболее удалённых» позиций внутри сценария — заглушка, не перебор (помечено в `notes`).
  Стартовые моменты (`magmom`) — спиновые, Гортер.

## 6. Ms0 (`moments.Ms0(composition, hypothesis)`)

Коллинеарная ферримагнитная модель Гортера: M0 [μB/ф.е.] = Σ_i σ_i Σ_s N_i p[s,i] m(s); σ_i = +1 для W3, W4, W5, W7
(12 позиций вверх), −1 для W1, W2, W6 (6 вниз). Схема совпадает с уточнённой в fit: знаки моментов L01 Fig. 4 (Mg, Ni),
L02 SrZn2W (hex-оси; знак W4 в таблице S3 — задокументированная ошибка извлечения, CONFLICTS B.3) и L05 DFT (тест
`test_gorter_scheme_matches_the_fit_moments`).

Моменты ионов (**допущения**, `identifiable=False`, не литературные числа): спиновые g·S·μB: Fe³⁺ 5, Fe²⁺ 4, Co²⁺ 3
(L02 тоже фиксирует Fe³⁺:Co²⁺ = 5:3), Ni²⁺ 2, Mn²⁺ 5, Mn³⁺ 4, Zn/Mg 0. Орбитальный вклад (сверх спина, параллельно):
Co²⁺ U(0, 1), Fe²⁺ U(0, 0.5), Ni²⁺ U(0, 0.3), Mn³⁺ U(−0.3, 0) μB; в fit нет значения орбитального момента Co (L05 даёт
только Fe, ≈0.02 μB). Допущенные авторами L11 моменты (Co 4.0, Ni 3.0, Mn 2.7) не используются (tier 3, CONFLICTS F);
диапазон Co лишь содержит 4.0.

Содержание A: фактическое = r·x, r ~ U(0.85, 1) (допущение по уточнённым содержаниям fit: Co 0.855, Zn 0.90, Mg 0.845 от
номинала; L03: Me < 2 на воздухе); `content_ratio=(1, 1)` — ровно номинальный состав. Fe²⁺ и все остальные величины
пересчитываются для фактического содержания. При `Ms0(…, draws=JointDraws)` **r и валентная ветка Mn берутся из общих выборок**
(`hexw.params.anisotropy.JointDraws`: те же r для Ms0, T_C и K; та же ветка Mn²⁺/Mn³⁺), `content_ratio` игнорируется. Сценарии Fe²⁺
разыгрываются с весами из §3.

Выход `Ms0Result`: выборки μB/ф.е., A·m²/кг, A/м; `summary()` — mean/std/медиана/p16/p84/p2.5/p97.5;
`by_hypothesis()`; `spin_only_*` (без орбитальных вкладов). Масса ф.е. — из стехиометрии (стандартные атомные массы);
A/м = M·μB / V_ф.е., V_ф.е. = (√3/2)·a²·c/2 из решёток fit (L02 Co/CoZn/Zn, L01 Mg/Ni: правило смесей по долям A; для Mn
и x-зависимости — разброс измеренных объёмов + 0.4 %). `Ms0` — значение при 0 K; Ms(T) — `ms_T` (ниже).

### Ms(T) = η·Ms0·m(T) и параметр η

Ms(T) = η · Ms0 · m(T/T_C) (`moments.ms_T`, общие выборки r, ветка Mn, T_C, форма m). **η — эффективный множитель** (ковалентное
снижение моментов относительно ионных значений, неколлинеарность, недонасыщение VSM), а не физическая константа иона. Оценка — по
fit-образцам, у которых Ms измерена при известной T: η_j = Ms_obs(300 K) / (Ms0_j · m(300 K / T_C,j)); для двух образцов L01 T_C — измеренный
(ТГ, L01-070/-078), для C004 — T0 модели (T_C SrFe18O27 в fit нет).

| образец | rec_id (Ms; T_C) | Ms_obs(300 K), А·м²/кг | Ms0 модели, А·м²/кг | m(300 K) | η_j (медиана, p16–p84) |
|---|---|---|---|---|---|
| SrFe18O27 | C004-002/-004/-006 | 81.07 | 105.4 | 0.926 | 0.830 (0.807–0.854) |
| SrMg2W | L01-069; L01-070 | 63.7 (VSM, поправка на примесь) | 85.7 | 0.904 | 0.821 (0.795–0.850) |
| SrNi2W | L01-077; L01-078 | 69.0 (VSM, поправка на примесь) | 101.3 | 0.918 | 0.742 (0.721–0.764) |

Три образца → один параметр с **межобразцовым разбросом** s(ln η) = 0.063 (медиана); для нового образца η берётся из предсказательного
распределения (Стьюдент, 2 dof): среднее ln η = −0.227, **η ≈ 0.80, 95 %: 0.57–1.11** (p16–p84: 0.72–0.88; верхний хвост > 1 — следствие
2 dof, физически η ≲ 1). Оценка `Ms_eta_moment_reduction`: роль `literature_fit`, статус `derived_by_us`.
**Исправление прежнего утверждения**: ранее говорилось, что Ms(300 K)/Ms0 «согласуется» с m(T). Это неверно: m(300 K / T_C) ≈ 0.90–0.93
(T_C = 700–790 K), а наблюдаемое отношение Ms(300 K)/Ms0 — 0.67–0.77; недостающий множитель ≈ 0.74–0.83 и есть η. Поэтому Ms(300 K) =
η·Ms0·m ≈ 0.75·Ms0 для SrFe18O27, а не Ms0·m.

## 7. Проверка на fit-литературе (не на holdout)

Это проверки, не калибровка: моменты L01/L02 измерены при 300 K, модель — 0 K, определения моментов разные
(`moment_definition`: L01 — среднее по позиции с диамагнитными ионами, L02/L05 — момент иона Fe), поэтому смешивать их
в подгонке нельзя (`SiteMoment` отказывается сравнивать разные определения).

* **L05 (DFT, 0 K), SrFe18O27**: 54.991 μB/ячейка = **27.50 μB/ф.е.**; модель Гортера (спиновая): 28.0 (Fe²⁺ на W3, W4),
  29.0 (W5, W6), 29.33 (по всем позициям); DFT ниже минимума ансамбля на 0.51 μB (ожидаемо: в `total` DFT сумма по PAW-сферам
  даёт 48.9 из 55.0, остальное — межузельный вклад; CONFLICTS F). Ближе всего сценарий Fe²⁺ на октаэдрах S-блока
  (W3, W4), но в параметры это не передаётся.
* **L02 SrZn2W (300 K), моменты Fe³⁺**: |m| = 3.99, 4.51, 2.99, 3.55, 3.09, 4.35, 3.79 μB (W1…W7), т.е. 0.60–0.90 от
  ионного значения 5 μB; ни один не превышает его (ожидаемое снижение при 300 K).
* **L01 Mg, Ni (300 K), средние по позиции моменты** против модели Гортера (0 K) по наблюдаемым заселённостям: W1, W2, W6
  в пределах ~2σ (−4.5 против −4.83; −4.2 против −4.88; −4.7 против −5.0 для Mg); моменты вверх-позиций (W4, W5, W7)
  меньше модельных на 0.9–1.5 μB (отношение 0.70–0.80, напр. Mg W5: 3.5/5.0), — снижение при 300 K (в L02 SrZn2W то же отношение 0.60–0.90, W5: 0.62); одной m(T) оно не объясняется (m(300 K) ≈ 0.90–0.93), недостающее —
  η (ниже); z-оценки без поправки (до −7.5) не информативны. Ms из нейтронных моментов (41 и 50 A·m²/кг) и VSM при
  300 K (60.3/63.7 для Mg, 67.7/69.0 для Ni) сравнимы лишь с оговорками: модель (0 K, x = 1.689 / 2.0): Mg
  86 [85, 87] A·m²/кг, Ni 101 [100, 103]; отношение VSM/модель 0.70 (Mg), 0.67 (Ni). Ms из NPD существенно ниже VSM и

* **C004 (SrFe18O27, 300 K)**: Ms = 81.0–81.1 A·m²/кг; модель при 0 K — 105.5 [103.5, 107.6] (x = 0): отношение 0.77. Это отношение
  не равно m(300 K) ≈ 0.93: остаток — η = 0.83 (§6). C004, L01 Mg и Ni — те самые три образца, по которым η оценён, поэтому это не
  независимая проверка.
Прогнозы фиксируются до проверки на отложенных данных и лабораторных данных; параметры здесь не подгонялись
под них.

## 8. Допущения и ограничения (сводка)

* Допущения (все `identifiable=False`/`assumption`): T_f, σ_sys ~ U(0.01, 0.03), приор Mn, веса валентных гипотез Mn (0.5/0.5), набор
  сценариев Fe²⁺ и σ = 1 μB их весов по моменту L05 (веса 0.63 / 0.23 / 0.13), ионные моменты и орбитальные диапазоны, отношение содержания A r ~ U(0.85, 1), 0.4 % на объём.
* Почти насыщенная подгонка: устойчиво идентифицируемы 6 d из 22 оценённых (10 при σ_sys = 0.01) на 40 измерений; остальные — только пределы.
* d не зависит от x (проверено лишь смесью Co+Zn).
* Гортер, 0 K, нет неколлинеарности (L02: Co-образцы планарные, неколлинеарные моды); Ms(T) = η·Ms0·m(T) с эффективным η ≈ 0.80
  (95 %: 0.57–1.11) по трём образцам fit.
* Fe²⁺ не локализован данными; DFT-конфигурации — заглушка размещения Fe²⁺.
* Границы применимости: x ≤ 2; сорта Co, Zn, Mg, Ni, Mn.
