# Модели T_C, m(T) и анизотропии K(x, T) (hexw.params.curie, hexw.params.anisotropy)

Этап 4B (круг 1 после физического ревью). Только fit-литература (`literature/fit/records_fit.yaml`) и физика. Holdout и vault
не используются. Всё, чего нет в записи fit, — именованное допущение (ASSUMPTION): в `ParameterEstimate` оно имеет
`source_id="ASSUMPTION…"`, роль `assumption` (не входит в `LEAKY_ROLES`) и `provenance.status="assumption"`; смешанных записей
нет (допущение и записи fit — две разные оценки). Магнитное ядро — `docs/MAGNET_MODEL.md` (θ от оси c, J/m³,
F = K1 s² + K2 s⁴ + K3 s⁶ + K4 s⁶ cos6φ). Литературное «K3 sin⁶θ cos6φ» = наш K4 (`map_literature_constants`, MAGNET_MODEL §2.1).

## 1. API

| вызов | результат |
|---|---|
| `curie.tc(composition)` | `Dist` T_C [K], определение dmax (L02) |
| `curie.ms_reduced(T, composition)` | `Dist` m(T) = M(T)/M(0), форма (nT, n) |
| `anisotropy.joint_draws(n, seed, n_prior, host=, co_form=, l11_constraint=)` | `JointDraws`: общие выборки для T_C, m, K1..K4 и `moments.Ms0/ms_T` (§4.4) |
| `anisotropy.anisotropy(composition, T, host='dft'\|'l11', co_form='ion_mf'\|'cc_power', l11_constraint='none'\|'co_zn_ratio')` | `AnisotropyResult` = (K1, K2, K3, K4) `Dist` [J/m³] + `p_state` (вероятности axis/plane/cone) |
| `anisotropy.anisotropy_branches(composition, T)` | все 8 альтернатив {(host, co_form, l11_constraint): результат}; **не усредняются** |
| `anisotropy.reorientation_temperature(composition, …)` | `Dist` T_T [K] (NaN в выборке = плоскость не глобальный минимум при низких T или перехода нет; `extra['p_none']`) |
| `anisotropy.fit_residuals(draws)`, `anisotropy.l11_ratio_tension(co_form)` | остатки на fit; апостериорное отношение \|K1(Co2)\|/\|K1(Zn2)\| против L11 |
| `moments.ms_T(T, composition, draws=)` | Ms(T) = η·Ms0·m(T) (STRUCTURE_MODEL §6) |
| `curie.curie_parameter_estimates()`, `anisotropy.anisotropy_parameter_estimates()` | `ParameterEstimate` (роль `literature_fit` с provenance по rec_id или `assumption`) |

`composition` = `{'Co': x, 'Zn': y, 'Mn': z, …}` — число атомов A на ф.е. SrFe(18−x)A(x)O27, x_tot ≤ 2; `{}` = SrFe18O27
(x = 0 поддерживается явно, без обходных приёмов). Нулевые элементы состава ничего не меняют (`{'Co': 2, 'Zn': 0}` ≡ `{'Co': 2}`,
в том числе для разброса интерполяции T_C).
`Dist`: выборка (`samples[..., i]` — i-й набор параметров; **все `Dist` из одного `JointDraws` совместны**), `median/lo/hi` (95 %),
`status`, `identifiable`, `basis`, `extra`. Статусы: `interpolated_in_series`, `series_interpolation`, `wide_prior`,
`transfer_tier3`, `extrapolated*`, **`extrapolated_in_T`** (T < 250 K), `measured_other_definition`, `assumed_zero` (K3),
`not_predicted` (samples=None). Без Pool, без записи на диск.

## 2. T_C(состав)

Данные: L02 Таблица 3 (L02-023/025/027/029/031: 790, 720, 700, 650, 590 K; определение — максимум |dM/dT|, 50–100 Oe, нагрев
10 K/min, «dmax»), L02 аннотация (L02-034/035: 780, 680 — альтернатива), L01 Mg/Ni (L01-070: 708.15 ± 2, L01-078: 773.15 ± 2 K,
пересечение касательных ТГ). Определения не смешиваются: модельная шкала «dmax»; значения ТГ входят через сдвиг
d_def ~ N(0, 15 K) (ASSUMPTION: на одном образце не измерялись).

Модель: линейное разбавление T_C(x) = T0 − Σ s_A x_A. Для ряда Co–Zn (x_Co + x_Zn = 2) T0 и s_Co сокращаются: это
взвешенная прямая через 5 точек L02 (2 параметра, 3 dof; интерполяция внутри ряда). Основное значение — по таблице;
расхождение с аннотацией (10 и 20 K при x_Zn = 0, 1) добавлено в σ точки (⊕ 10 K считывания производной). Прямая:
T_C = 778.4 − 91.7·x_Zn K, χ²/dof = 3.7/3; rms невязок 13.9 K добавляется как разброс интерполяции. **Разброс интерполяции
независим по составам**: для каждого состава он берётся из N(0, 13.9 K) с зерном, зависящим от состава (а не одно число на все
составы одной выборки); для одного и того же состава и тех же выборок он воспроизводим.

Вне определяемой области: s_Co ~ U(0, 50) K (ASSUMPTION; фиксирует T0 хозяина, которого нет в fit) → статус
`extrapolated_from_endpoints`, identifiable=False; x = 0 (SrFe18O27) — `wide_prior` (T0 = T_Co2 + 2 s_Co); Mn: s_Mn = f_Mn·s_Zn,
f_Mn ~ U(0,1), нет Mn T_C в fit → `wide_prior`; Mg/Ni при x = 2: значение ТГ со сдвигом d_def (`measured_other_definition`).

## 3. m(T/T_C)

Кузьмин: m = [1 − s t^{3/2} − (1−s) t^{5/2}]^{1/3}, t = T/T_C; s ~ U(0.3, 1.5) (ASSUMPTION: M(T) в L02-036 — только рисунок,
не оцифрован). Альтернатива — среднеполевая Бриллюэн S = 5/2 (`form='brillouin'`); для подрешётки Co²⁺ (S = 3/2) используется
`brillouin_m(t, 3/2)`. Таблица `_brillouin_table`: параметр y = 3S/(S+1)·m/t, m = B_S(y), t = 3S/(S+1)·m/y; **пределы**: y → ∞ даёт
m → 1, t → 0; y → 0 даёт m → 0, t → 1 (точка Кюри, добавлена точно); при малых y формула не считается разностью двух котангенсов
(потеря точности): сетка начинается с y = 0.02. Итог: m(0) = 1, m(1) = 0 точно, m монотонно убывает; тест сверяет m(t = 0.5) для
S = 5/2 с независимым `fsolve` самосогласованного уравнения. Ms(T) = η·Ms0·m(T): η — эффективный множитель, оценка в
STRUCTURE_MODEL §6. Это одна эффективная намагниченность ферримагнетика; **многоподрешёточная термодинамика (ТЗ §9.2) — следующий этап**.

## 4. Модель анизотропии

### 4.1 Формулы

K1(x,T) = [K_Fe + (x_Co + x_Zn)(A − K_Fe)/2 + x_Mn (A_Mn − K_Fe)/2] · m³ − ρ·A·x_Co·F_Co(T) (+ вклад Mn, §4.5)  
K2 = q2·K_scale·m¹⁰ (l = 4), K3 = 0 (допущение, нет данных), K4 = q4·K_scale·m²¹ (l = 6),  
**K_scale = \|скобка\| + ρ·A·x_Co/2 (+ вклад Mn³⁺)** — полный одноионный вклад, а не только A хозяина (для Co-богатых составов
K_scale/A > 2: при масштабе одного A приоры K2, K4 были бы занижены).

* A = K1 хозяина SrZn2W при 0 K (осевая: L02-047), K_Fe = K1 SrFe18O27 при 0 K, A_Mn — Mn2.
* Каллен–Каллен: K_l ∝ m^{l(l+1)/2}; хозяин (Fe³⁺, S-состояние) — l = 2 → m³.

### 4.2 Две структурные формы Co²⁺-вклада (`co_form`; обе возвращаются, не усредняются)

Для Co²⁺ (S = 3/2) одноионные операторы имеют только ранг l = 2, поэтому K_Co ∝ ⟨O₂⟩ ∝ m_ion³ (l(l+1)/2 = 3); **показатель
p ≈ 13 ≫ 3 не вытекает из теоремы Каллена–Каллена** и может быть только эффективным.

* **`ion_mf` (по умолчанию)**: F = m_ion(T/Θ_Co)³, m_ion — среднеполевая Бриллюэн S = 3/2, Θ_Co = f·T_C образца, f ~ U(0.15, 1).
  Подрешётка Co²⁺ следует собственному молекулярному полю → параметры (ρ, f); показателя нет.
* **`cc_power`**: F = m^p, p ~ U(3, 21) — **эффективный** показатель (l = 2…6), не следствие теоремы; `p` → `identifiable=False`
  (идентифицируема комбинация данных — вклад Co в K1 при 300 K, оценка `aniso_CoTerm_over_host_300K_Co2[…]`).
* ρ — \|вклад Co²⁺\| / A на один Co при 0 K, log-равномерный на (0.5, 50), **усечён явным допущением** (§4.3).
* q2, q4 — безразмерные приоры (K2, K4 не идентифицируемы).

### 4.3 Потолок одноионной энергии Co (ASSUMPTION)

Одноионная энергия Co²⁺ при 0 K, ρ·A·V_fu, **не выше E_CO_MAX = 20 мэВ/ион** — явное допущение (масштаб спин-орбитальной
энергии 3d-иона в искажённом кислородном окружении; не литературное число). Реализация: апостериор ρ ресэмплируется (усекается)
по этому ограничению для хозяина каждой выборки (`JointDraws.n_cap_resampled`, порядка 8 % выборок). Оценка
`aniso_E_Co_max_meV` — `assumption`. Для A ≈ 145 кДж/м³ (V_fu ≈ 4.9·10⁻²⁸ м³) потолок ρ ≲ 45: он срезает только хвост.

### 4.4 Совместные выборки (`JointDraws`)

Один индекс i — один набор параметров для T_C, m, K1..K4 и Ms0:
* **общий r ~ U(0.85, 1)** (отношение фактического содержания A к номинальному) для Ms0, T_C и K (`tc_params['content_scale'] = r / R_FIT`);
* **общая валентная ветка Mn** (`mn_valence` 2|3) для Ms0 и K;
* `tc_scatter` независим по составам (§2);
* ветвь (host, co_form, l11_constraint) фиксирована для объекта; случайные числа величин, от ветви не зависящих (T_C, r, ветка Mn,
  множитель низких T), **общие** у всех ветвей при одинаковых (n, seed);
* x = 0 (SrFe18O27) и составы с нулями поддержаны явно (тест `test_x0_is_supported_without_a_hack`).

### 4.5 Mn (знак K1 по валентной гипотезе 4A, совместные выборки)

* **Mn²⁺** (S-ион): ось с весом 0.85 (ASSUMPTION), масштаб как у хозяина (\|A_Mn\|); знак ± по этому весу.
* **Mn³⁺** (Ян–Теллер): та же форма, что Co-ветка (одноионный вклад ρ_Mn·A·x_Mn·F), знак 50/50 (ASSUMPTION).
* Веса — ASSUMPTION (`aniso_Mn2_axial_weight`, `aniso_Mn3_axial_weight`). A_Mn: L11 BaMn2W (Ha), tier 3; σ_ln = 1.0 (с запасом);
  **аномальный Ms образца L11-Mn (47.8 А·м²/кг против 73–95 у остальных образцов серии)** и спорный момент Mn²⁺ (L11-016) делают
  этот масштаб слабым. Статус Mn — `transfer_tier3`, identifiable=False.

### 4.6 Область по T

K(x, T) при **T < 250 K** — `extrapolated_in_T`: fit ограничивает только T_T ≥ 265 K и состояния при 300 K. Интервал расширяется
логнормальным множителем, σ растёт линейно от 0 при 250 K до 0.7 при 0 K (ASSUMPTION; фактор ≈ 2 на 1σ). Признак — `extra['T_extrapolated']`.

## 5. Подгонка (L02)

Данные: T_T (L02-024/026/028/030: 555, 450, 405, 265 K, «dmax») при измеренных T_C тех же образцов; σ_T_T = 10 K ⊕ \|table − text onset\|
(L02-032/033: 520 vs 555, 360 vs 405 K → 35 и 45 K; для x = 0.5, 1.5 — среднее 42.5 K, допущение). Жёсткие ограничения: Zn2 без
перехода и ось на всём 0 < t < 1 (L02-032/047), плоскость при 300 K для x_Zn = 0, 1 (L02-045/046). **Плоскость должна быть
ГЛОБАЛЬНЫМ минимумом** (`easy_state`) при низких T, а не метастабильным локальным (иначе при q2 < −0.5 у SrZn2W возникала бы
«реориентация» из метастабильной плоскости). Критерий T_T: первый выход из плоскости при нагреве, K1 + 2K2 = 0. Метод: self-normalised
importance sampling (SIR) из приоров 200 000 набросков; профиль χ²: `chi2_profile()`. Граница при 300 K (L02-037, x_Co = 0.65,
«assumed_by_authors») в подгонку не входит.

## 6. Масштаб K1 (хозяин): альтернативы, не усредняются

* **`host='dft'` (по умолчанию)**: L05-103, Ku(SrFe18O27, GGA+U+SOC, 0 K) = 0.148 МДж/м³ (эффективная K1+2K2), логнормаль σ_ln = 0.5
  (ASSUMPTION; 3 метода L05 согласуются «по тренду»); A = K_Fe·LN(0, 0.5) (ASSUMPTION: Zn2 DFT в fit нет); Mn — отношение L11
  Mn/Zn ⊗ LN(0, 1.0). Вторичная экспериментальная цитата из L05 (исключена) **не используется**.
  95 %: K_Fe 54–388, A 37–530 кДж/м³.
* **`host='l11'`**: L11-001/003 (Fe), 010/012 (Zn), 013/015 (Mn), BaMe2W, 300 K, tier 3: \|K1\| = μ0Ha·Ms/2, Ms = σ·ρ_d, затем пересчёт на 0 K
  делением на m³(300 K/T_C). **Закон приближения к насыщению даёт только \|K\| (знак теряется), K2 = 0 принято авторами, и он
  применим лишь при H ≫ Ha; это условие в записях L11 не подтверждено и считается невыполненным** (запись L11 сама отмечает, что для
  планарного Co2W одноосная формула неприменима). Поэтому оценка — порядок величины: σ_ln = 0.8 (не 0.5), Mn — 1.0; Co в базе не используется.
* **Перенос Ba → Sr обоснован внутри fit**: чувствительность DFT-Ku L05 к Ba (тот же метод): K(SrW) = 0.148 МДж/м³ (L05-103),
  K(Sr₀.₅Ba₀.₅W) = 0.301 МДж/м³ (L05-112). В линейной по доле Ba модели K(y) = K_Sr + (K_Ba − K_Sr)y имеем K_Ba = 2K(0.5) − K(0) =
  0.454 МДж/м³; множитель K(Sr)/K(Ba) = **0.326**; линейность — допущение, σ_ln множителя = 0.4 (показатель q в K ~ y^q ∈ [0.5, 2] даёт 0.20–0.41).
  95 %: K_Fe 27–816, A 21–662 кДж/м³ — шире DFT-хозяина.
* После переноса медианы K_Fe близки (148 против 146 кДж/м³), A: 145 (DFT) против 120 (L11); интервалы L11 шире в несколько раз.

## 10. K2, K4, неидентифицируемое; правило identifiable

* K2 = q2·K_scale·m¹⁰ (q2 ~ N(0, 0.3); апостериор сдвинут к отрицательным значениям: −0.25 у `ion_mf`), K3 = 0 (допущение),
  K4 = q4·K_scale·m²¹ (q4 ~ N(0, 0.03)) — только приор. K_scale включает полный одноионный вклад (§4.1).
* **Правило `identifiable` оценок**: оценка идентифицируема, только если 95 %-ширина апостериора **меньше половины** ширины приора
  (сужение ≥ 2×); иначе `identifiable=False`, и в оценке указан интервал приора. Результат: идентифицируемы лишь комбинации
  `aniso_CoTerm_over_host_300K_Co2[…]` (ширина апостериора/приора 0.32 / 0.23) и ρ для `cc_power` (0.45); **не** идентифицируемы
  ρ для `ion_mf` (0.82), f (0.77), p (0.77), q2 (0.70), q4 (1.0), масштаб хозяина.
* Не определяются: абсолютный масштаб A, K_Fe; K2, K3, K4; ρ и p/f по отдельности; различие «конус/ось» выше T_T; реориентации
  при T < 250 K (нужна оцифровка L02-036, Fig. S6a); температурная зависимость Co²⁺-вклада за пределами принятых форм.
* Допущение о составе: номинальные x_Zn; уточнённые заселённости L02 (Co 0.84/Zn 0.81 для CoZn) отличаются — это учитывает общий r.
