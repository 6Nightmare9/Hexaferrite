# HexW 0.2: начало работы

Проект находится в `C:\MIPT\working_stuff\Hexx`. Код, расчёты и контрольные точки сохраняются здесь; флешка для работы не требуется.

## Запуск

1. Откройте `START_HEXW.cmd` в папке проекта. Не закрывайте появившееся окно во время вычислений.
2. Откройте в своём браузере `http://127.0.0.1:8765`.
3. Во вкладке «Расчёт» нажмите «Заполнить пример Co–Zn». Проверьте состав, температуру, поля и диапазон частот. Кнопка заполняет форму; запуск выполняется отдельной кнопкой «Рассчитать».
4. Нажмите «Рассчитать». Одна задача выполняется за раз, с пониженным приоритетом и ограничением численных библиотек двумя потоками.
5. Откройте результат: графики, таблицы, параметры, структурные гипотезы и CIF. Исходные данные не изменяются.

Если интерфейс уже работает на этом адресе, повторный запуск не нужен. Закрытие вкладки браузера не останавливает сервер; при запуске через START_HEXW.cmd для остановки нажмите Ctrl+C в его окне и дождитесь завершения текущей задачи. Если адрес занят уже запущенной копией, используйте открытый сервер. Другой порт можно задать командой `python -m hexw serve --port 8766` в подготовленном окружении.

## С чего начать после передачи проекта

Во вкладке «Результаты» уже есть девять завершённых прогнозов. Текущие версии: Co₂ `ec1f232e28e4ba5929b3`, CoZn `2fb8d861e571130ff1b9`, Zn₂ `74961425c1b88fa91691`, Mn₁ `f1ae25e45782e53f802a`, Mn₂ `b5f5307af271a12d5980`, Mg₁ `d5aaa5264afdd1041856`, Mg₂ `9c45d2a71a16521a51e0`, Ni₁ `1c32f4f97fd926d5b4bc`, Ni₂ `cd2f0759c1eb6c6a912c`. Старые прогнозы сохранены и отмечены как архивные. Для знакомства откройте CoZn, затем график зависимости частоты от поля и спектры. Условия этой серии: 300 K, поля 0 / 0.3 / 0.8 T, сферический образец, g = 2, α = 0.02, 48 реализаций.

Для собственной задачи сначала согласуйте определение измеряемой величины и условия, задайте их в «Расчёт», проверьте статус применимости и сохраните прогноз. Далее зафиксируйте его в «Проверка модели». Обработайте эксперимент отдельно и только затем сравнивайте одинаковые величины. Файл `config/validation_targets_example.json` — защищённый от случайного использования шаблон целей: замените заполнители реальными измерениями, укажите их происхождение и ошибки, проверьте состав/поле/температуру/геометрию/единицы и установите `template_only=false`. Значения из прогноза нельзя копировать в измеренный ответ. Обычный интерфейс не калибрует модель по измерениям.

Параметры «диск» и углы описывают выбранную геометрию и ориентацию материала. По одной формуле не определяются автоматически реальная текстура, пористость или многодоменное состояние поликристаллического образца.

## Поддерживаемые составы

Семейство: **SrFe₁₈₋ₓAₓO₂₇**, A = Co, Zn, Mn, Mg, Ni, суммарно 0 ≤ x ≤ 2. Примеры: `SrCo1Zn1Fe16O27`, `SrMn1Fe17O27`, `SrMg2Fe16O27`, `SrNi1Fe17O27`.

Система не переносит эту модель автоматически на Ba, другие металлы, кислородные дефекты или x > 2. Математическая поддержка смешанного состава ещё не означает его экспериментальную проверку.

## Что означает результат

- CIF описывает **кандидат на литературном геометрическом шаблоне**, с частичными заселённостями. Это не результат релаксации данного состава и не готовый атомный вход DFT.
- Mₛ(T) и T꜀ получены из модели моментов, распределения катионов, литературных температур и эффективного уменьшения момента. Для Mn остаётся существенная неопределённость валентности и температуры Кюри.
- Co–Zn: температурная переориентация опирается на литературу; абсолютная анизотропия и высокие порядки определены существенно слабее.
- Mn/Mg/Ni в режиме `auto`: поле анизотропии при комнатной температуре берётся из первичного графика по стронциевым монокристаллам. Оцифровка и перенос к другому образцу имеют отдельные неопределённости. Изученные пределы x: Mn — 2; Mg — 1.7; Ni — 1. За их пределами результат обозначается как экстраполяция. Температурная зависимость вне 300 K — физическое предположение с расширением интервала.
- Показанная собственная частота — низшая недемпфированная мода устойчивого основного состояния однородной модели. Максимум поглощения рассчитывается отдельно и может отличаться.
- χ относительно внешнего поля и собственный тензор μ относительно внутреннего поля сохраняются отдельно. Модель измерительной ячейки здесь не используется.
- `g` и `α` в форме — **вводимые сценарные параметры**. Значения 2 и 0.02 не являются измеренными универсальными константами материала.
- Полосы 95% — разброс принятых параметрических сценариев. Он не является гарантированной экспериментальной погрешностью. 48 реализаций достаточно для демонстрации; для количественного исследования нужна проверка устойчивости интервалов при увеличении выборки и изменении физической ветки.
- Средний спектр усредняет неопределённые параметры, а не доказывает физическое неоднородное уширение образца. Мелкие пики средней кривой при небольшой выборке могут быть следствием конечного числа сценариев; это не найденные обменные моды. Не используйте FWHM такой кривой как измеренное собственное демпфирование.

## Экспериментальные файлы

Перед открытием измерений зафиксируйте завершённый прогноз во вкладке «Проверка модели». Фиксация связывает исходный код, версии численных библиотек, литературные данные, настройки, параметры и результаты контрольными суммами. Обработка измерения не меняет эти параметры.

**РФА:** `.mdi` или текстовая таблица «2θ, интенсивность». Укажите длину волны. Доступны поиск пиков, d-расстояния, оценка Шеррера при известном инструментальном уширении и первичная подгонка по фиксированному CIF. Последняя проверяет согласие картины, но не выдаёт количественные фазовые доли и не заменяет полный Ритвельд. Для него потребуются инструментальный профиль и структуры всех фаз.

**Мёссбауэр:** текстовый `.spc` или таблица «скорость, счёт». Для физических параметров нужна подтверждённая калибровка относительно α-Fe. Заголовок прибора сам по себе не является калибровкой. Без неё сохраняются данные и график по каналам. Для калиброванных данных доступны альтернативы из нескольких секстетов, изомерный сдвиг, магнитное поле, квадрупольная поправка первого порядка, ширины, остатки, локальная ковариация и критерии выбора. Это тонкий поглотитель; распределения полей, релаксация и поправки на толщину пока не реализованы. Секстеты не назначаются автоматически семи узлам решётки.

**РЭМ:** изображение, подтверждённый масштаб `um_per_pixel`, область без подписей и масштабной линейки. Смотрите маску и наложение. Соприкасающиеся зёрна могут объединяться; можно передать исправленную маску. Результат — статистика объектов на 2D изображении. Он не заменяет размер кристаллитов РФА, трёхмерную статистику или атомные координаты.

**EDS:** CSV с колонками `element,weight_percent,std_weight_percent` (последняя необязательна). Принимается уже количественно обработанный экспорт прибора. Рассчитываются атомные отношения и распространение заданных ошибок; кислородная стехиометрия не навязывается. Не выполняется самостоятельная ZAF-коррекция сырого спектра. Валентность и занятость узлов из EDS не назначаются.

**ФМР:** таблица «ось, сигнал», единицы оси, тип сигнала и фон. Поддерживаются поглощение и уже измеренная производная. Обрезанный или неоднозначный пик не получает фиктивную ширину. Ширина производной не подменяет FWHM поглощения.

Файлы с прежними подгонками и прежними прогнозами не становятся измеренными ответами. Для известных ранее исследованных данных сохраняется ретроспективный статус сравнения.

## Дополнительные физические модули

Многоподрешёточная LLG реализована отдельно и проверена на пределах одной подрешётки и двухподрешёточного антиферромагнетика. Ей нужны явная матрица обменных взаимодействий, моменты, анизотропия и происхождение параметров. Программа не выдаёт отсутствующие J как рассчитанные из формулы. Команда: `python -m hexw spin-model --config параметры.json`. Соглашение: `E=-Σ(i<j)Jij mi·mj`; J>0 — ферромагнитная связь, единицы матрицы — J/m³, моменты подрешёток — A/m с учётом кратности.

Диэлектрический модуль поддерживает пассивную дисперсию Дебая и проводимость с явными параметрами. Для пористости доступно изотропное приближение сферических пор Maxwell–Garnett. Без диэлектрических параметров ε помечается как непрогнозируемая, а не подставляется произвольное число. Эти входы можно задать в дополнительном JSON интерфейса или в YAML.

## Прерывание и восстановление

Расчёт сохраняется после подготовки параметров и после каждой пары «температура–поле». Повторите тот же запуск или выберите «Возобновить» для прерванного расчёта. При том же коде и входах завершённые точки повторно не вычисляются. При изменении кода или источников создаётся новая версия; совместимый кэш параметров используется только после проверки содержимого. Текущая незавершённая точка после аварийного отключения вычисляется заново.

Серия примеров запускается `scripts/run_material_series.py`: Co–Zn → Mn → Mg/Ni. Её итоговая контрольная точка хранится в `runs/material_series_2026-10-26/checkpoint.json`. Состояние всей работы — в `audit/PROJECT_STATE.json`.

## Границы текущей версии

**Погрешность ≤10% для ФМР не подтверждена.** Аналитические и синтетические тесты проверяют реализацию решателя; согласие с данными параметризации не является независимой проверкой. Доступных собственных измерений ФМР, диэлектрики и РЭМ недостаточно для такой аттестации.

Нет полной атомистической параметризации каждого состава, релаксации всех координат, проверенной по DFT матрицы J, модели динамики стенок доменов и полного количественного Ритвельда. Полный доступ к компьютеру не устраняет эти научные пробелы. Набор выбранных сценариев работает как воспроизводимый исследовательский инструмент; следующий этап выбирается после рассмотрения результатов с коллегами.
