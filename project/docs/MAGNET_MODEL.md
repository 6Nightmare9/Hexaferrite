# Быстрая магнитная модель (hexw.theory.magnet)

Ядро ТЗ §9.1–9.3: макроспин, равновесие, ФМР, восприимчивость, ширины линий. Параметров материала в коде нет:
`Ms`, `K1..K4`, `N`, `alpha`, `g`/`gamma` задаёт вызывающий. Тесты используют только помеченные `SYNTHETIC` значения
(`tests/theory/_synth.py`). Модуль ничего не читает с диска, при импорте не создаёт Pool и не пишет файлы.

## 1. Единицы и обозначения (SI)

| величина | единица | примечание |
|---|---|---|
| `Ms` | A/m | |
| `K_i` | J/m³ | магнитокристаллические, форма отдельно через `N` |
| `B` в API = μ0·H_ext | T | приложенное поле, НЕ индукция внутри образца (ТЗ §5) |
| `mu0_HA`, `mu0Ms` | T | μ0H_A = 2K1/Ms (c-состояние), μ0Ms |
| `mu0_H_theta_basal`, `mu0_H_phi_basal` | T | (−2K1−4K2−6K3+6\|K4\|)/Ms и 36\|K4\|/Ms (базисное состояние) |
| γ | rad/(s·T) | `gamma_rad_per_s_T` |
| γ/2π | Hz/T | `gamma_over_2pi_Hz_per_T`; g=2 даёт ≈27.99 GHz/T |
| f | Hz, ω = 2πf rad/s | |
| α | — | параметр Гильберта, обязательный аргумент |

γ задаётся ровно одним из `g`, `gamma_over_2pi_Hz_per_T`, `gamma_rad_per_s_T` (`resolve_gamma`, `Gyro`);
значения по умолчанию нет, комбинации и отсутствие дают `ValueError`. Для g используется `hexw.units.gamma_from_g`.

## 2. Свободная энергия

Кристаллическая система: z ‖ c, θ от c, φ азимут (x — произвольно выбранное направление в базисной плоскости).

F(m) = K1 sin²θ + K2 sin⁴θ + K3 sin⁶θ + K4 sin⁶θ cos6φ − Ms (B·m) + (μ0 Ms²/2) m·N·m,  [J/m³]

* `N` — тензор размагничивания образца в кристаллической системе, tr N = 1, симметричный, ≥0; допускается также
  нулевой тензор `no_shape()` («у объекта нет собственной формы», поле уже внутреннее — зёрна в режиме
  `macro_meanfield`). Форма в `K_i` не включается (иначе двойной счёт). Готовые: `sphere()`, `thin_disk_perp_c()` =
  diag(0,0,1) (плоскость диска ⟂ c), `thin_disk_parallel_c()` = diag(1,0,0) (нормаль диска ⟂ c, ось c лежит в
  плоскости), `ellipsoid(a,b,c)` — Osborn (квадратура интеграла, проверка tr N = 1).
* **Поле анизотропии c-состояния (θ = 0):** μ0H_A = **2K1/Ms**. K2, K3, K4 входят в F как O(θ⁴) и в частоту c-состояния
  не входят (прежняя запись 2(K1+2K2+3K3)/Ms была ошибочной). Для диска ⟂ c эффективное поле μ0H_A − μ0Ms.
* **Базисное состояние (θ = π/2).** Минимум члена K4 sin⁶θ cos6φ: **cos6φ0 = −sgn(K4)**. Поэтому φ0 = kπ/3 только при
  K4 < 0; при K4 > 0 минимумы лежат на φ0 = π/6 + kπ/3 (30° + k·60°). Эффективные поля двух поперечных мод:
  **μ0H_θ = (−2K1 − 4K2 − 6K3 + 6|K4|)/Ms**, **μ0H_φ = 36|K4|/Ms**, f = (γ/2π)√(H_θ H_φ) (+ Зееман/форма). Частота
  естественного ФМР зависит только от |K4|. (Прежнее «−6K4cos6φ0 / −36K4cos6φ0» верно в общем виде, но при cos6φ0 = 1 —
  лишь для K4 < 0.)
* Конус при H=0 (K3=K4=0, N изотропна): sin²θ0 = −K1/(2K2), K2>0, K1<0, sin²θ0<1 (`cone_angle_analytic`).
  Формула относится к «чистой» кристаллической части; форма сдвигает K1_eff.

### 2.1 Карта обозначений констант (литература ↔ код)

В литературе одна и та же шестикратная базисная константа называется по-разному. В коде **K4 — коэффициент при
sin⁶θ cos6φ**, а **K3 — коэффициент при sin⁶θ без азимутальной зависимости**.

| что написано в статье | что это | поле в коде |
|---|---|---|
| K1 sin²θ | одноосная, 2-й порядок | `K1` |
| K2 sin⁴θ | одноосная, 4-й порядок | `K2` |
| K3 sin⁶θ | одноосная, 6-й порядок (в коде есть) | `K3` |
| «K3 sin⁶θ cos6φ» (часто пишут именно так) | базисная 6-кратная | **`K4`** (а `K3` = 0, если члена sin⁶θ нет) |
| «K4 sin⁶θ cos6φ», «K6», «K_basal», «K_ab» | то же | `K4` |

Импорт параметров из статей — только через явную карту `map_literature_constants(constants, mapping)`:
`map_literature_constants({"K1": k1, "K2": k2, "K3": k3}, {"K1": "K1", "K2": "K2", "K3": "K4"})` → `{"K1","K2","K4"}`.
Каждая константа обязана быть в карте, цели уникальны и из {K1..K4}; неявного соответствия по имени нет. Знак и
определение (энергия на объём в J/m³ или эрг/см³; K с множителем 1/2 или без) проверяются вручную по статье.

## 3. Равновесие (`equilibrium.py`)

1. Затравки — **каждая** точка сетки Фибоначчи (по умолчанию 600, равновеликая) плюс симметричные (±x, ±y, ±z, ±B).
   Релаксация векторизована (`relax_batch`): римановы шаги Ньютона в собственном базисе 2×2 гессиана с |λ| (saddle-free,
   пол 1e-7·масштаб) в знаменателе, **шаг ограничен 0.25 рад** (экспоненциальное отображение на сфере), принимается
   только при невозрастании энергии (backtracking); седло покидается вдоль отрицательного собственного вектора. Хвост из
   ≤12 медленных точек добивается скалярным ядром на чистом Python (`_fast.ScalarKernel`).
2. **Контроль полноты.** Поиск повторяется на удвоенной сетке (`verify=True`). Если число различных минимумов изменилось —
   результат берётся с плотной сетки, `EquilibriumSet.status = 'possibly_incomplete'`, `possibly_incomplete = True` и запись
   в `notes`. Узкие бассейны (много уже расстояния между точками сетки) всё равно могут быть пропущены.
3. Кластеризация по углу (1e-4 рад). Устойчивость: собственные значения 2×2 гессиана на сфере
   `P ∇²F P − (m·∇F) P` ≥ −1e-9·масштаб. Нулевое собственное значение → `neutral`.
4. Осевая симметрия (K4=0, N осесимметричен, B⊥c=0): кольцо состояний сводится к одному представителю φ=0
   (`azimuthal_degenerate=True`). Полностью вырожденная энергия → статус `degenerate_isotropic`.
5. Классы: `axial` (m ∥ ±c), `planar` (m_z≈0), `cone` (промежуточный θ без поперечной компоненты поля, включая
   H=0), `tilted_by_field` (промежуточный θ при поперечном поле).
6. Метастабильные состояния: `EquilibriumSet.metastable = [(state, dE)]`, `dE` в J/m³; вырожденные с основным —
   в `ground_degenerate`.
7. История: `trace_branch` / `hysteresis_loop` ведут ветвь релаксацией предыдущего состояния (без глобального
   поиска). Скачок (смена направления на > 0.5 рад) отмечается `jumped`. Ветвь не «перескакивает» на глобальный минимум,
   пока остаётся локальным минимумом.

Регрессии: K1=−1e5, K2=3e5, K4=−1e3, сфера, H=0 → ровно 12 минимумов уже при n_grid=100/200 (раньше 9–11 в зависимости
от сетки); 60 случайных наборов против эталона из 20 000 точек — 0 пропусков (раньше 3–5 из 60).

## 4. ФМР (`fmr.py`)

Уравнение Гильберта: dm/dt = −γ m×B_eff + α m×dm/dt, B_eff = −(1/Ms)∂F/∂m [T].

* **(б) Линеаризованное LLG, основной метод.** Локальный базис (e1×e2 = m0), W = Hs/Ms [T]:
  ω = (γ/Ms) √det Hs (без затухания). **Единая толерантность** tol = 1e-9·масштаб энергии для `llg_omega`, `modes_at`,
  `sweep_branches`: λ_min < −tol → NaN (не минимум); min|λ| ≤ tol → **нейтральная мода, f = 0 ровно**, статус
  `neutral_zero_mode` (голдстоуновская мода макроспина: кольцо конуса при H ∥ c без K4; конечной частоты у однородной
  прецессии там нет). NaN на нейтральных ветвях (раньше чередовался с 0 из-за знака шума λ) больше не появляется.
* **(а) Смит–Бельерс.** ω = γ/(Ms sinθ) √(F_θθ F_φφ − F_θφ²). Особенность sinθ→0 обрабатывается сменой полюса:
  `pole='crystal'` при sinθ<1e-9 возвращает NaN со статусом `singular_pole` (без молчаливой регуляризации);
  `pole='local'` — полюс ⟂ m0 (sinθ'=1); `pole='auto'` переключается при sinθ<0.05. Производные считаются через
  `m_a·∇²F·m_b + ∇F·m_ab`, поэтому совпадение с (б) на машинной точности (≈2e-14).
* `f_res(model, B, θ_H, φ_H, ...)` — частоты ВСЕХ ветвей (локальных минимумов) в одном поле; `Mode.is_ground`,
  `Mode.dE`. `natural_fmr` — H=0.
* **Ветви вдоль развёртки (`sweep_branches`).** Ветвь ведётся от узла к узлу релаксацией предыдущего состояния (быстрое
  скалярное ядро; если прямой шаг не удался — адаптивное деление шага). Конец ветви (спинодаль, λ_min → 0) и рождение ветви
  находятся бисекцией (`Branch.B_death`, `B_birth`, причина `end_reason`: `spinodal` | `merged` | `range_end`); в этих
  точках f = 0. «Слияние» — вилка (pitchfork): пара симметричных минимумов (наклон вверх/вниз) сливается с центральным
  состоянием, у центральной ветви в этом поле тоже мягкая мода. **Глобальный поиск** минимумов — только на грубой
  подсетке (каждый `coarse_step`=8-й узел) и по событиям (λ_min ветви < 2% масштаба и убывает; ветвь исчезла/слилась);
  найденный новый минимум прослеживается назад до своего B_birth. Ограничение: пара минимумов, существующая лишь между двумя
  глобальными поисками и не связанная с мягкой модой активной ветви, может быть пропущена (`coarse_step=1` —
  исчерпывающий поиск).
* `H_res(model, f, θ_H, φ_H, B_range_T=(lo,hi), ...)` — все B с f_ветви(B) = f_target:
  1. смена знака f−f_target между узлами, в том числе с виртуальными концами ветви (B_birth/B_death, f = 0), уточнение
     brentq; корень, на котором скобка сошлась к разрыву, отвергается (в `notes`);
  2. дискретные экстремумы f(B) «не с той стороны» цели (3-точечный признак) уточняются минимизацией Брента, и в скобки
     добавляются узлы по обе стороны (узкий провал/всплеск, прячущий пару корней: одноосная сфера, B ⊥ c, f→0 при B=H_A);
  3. в поля спинодалей/слияний других ветвей вычисляется f данной ветви (вилка: у соседней ветви там провал f).
  Статус: `ok` | `no_resonance_in_range` (ничто не пересекает цель и нет подозрений) | **`possibly_incomplete`** —
  разрешение не позволяет исключить скрытые корни (оценка кривизны F=f² между узлами: отклонение хорды h²/8·|F″| больше
  расстояния до цели) или глобальный поиск пометил неполноту. Эта оценка эвристическая: она не видит провал, спрятанный
  между двумя узлами монотонного участка, если провал не связан с событием (спинодаль, слияние) — для надёжности
  увеличивайте `n_points`. Край диапазона никогда не подставляется. Корни от вырожденных состояний (например, пара
  наклонов ±θ) приходят с разными `branch_id` и одинаковым B — это разные состояния.
  Производительность: глобальный поиск не на каждом шаге, а на каждом 8-м и по событиям; шаги ветвей — на чистом Python
  (`_fast.py`), собственные значения 2×2 — в замкнутой форме (замеры до/после — в отчёте о доработке).
* Киттель как частные случаи (проверяются тестами): сфера f = (γ/2π)B; эллипсоид, поле ∥ x:
  f = (γ/2π)√((B+(Ny−Nx)μ0Ms)(B+(Nz−Nx)μ0Ms)); плёнка в плоскости √(B(B+μ0Ms)), нормаль: B−μ0Ms;
  плоскостное состояние в поле вдоль φ=0 при насыщении: f = (γ/2π)√(F_θ F_φ)/Ms с F_θ = B Ms + μ0Ms² − 2K1−4K2−6K3−6K4,
  F_φ = B Ms − 36K4 (для обоих знаков K4 при B, достаточном для m ∥ B); естественный ФМР базисного состояния —
  √(H_θ H_φ) из §2 с |K4|; осевое f = (γ/2π)·μ0H_A, μ0H_A = 2K1/Ms. Формулы Киттеля применимы только для однородной
  прецессии однодоменного эллипсоида в насыщенном/однозначном равновесии; общий метод — (б).
* Проверка LLG во времени: тест `test_chi_against_time_integration_of_gilbert_llg` (маркер `slow`) интегрирует
  уравнение Гильберта `solve_ivp` и сравнивает отклик на гармоническое поле с χ (расхождение ≲1e-4).

## 5. Восприимчивость (`susceptibility.py`)

* **Временная конвенция: exp(−iωt)**, χ = χ′ + iχ″. Потери: χ″_ii > 0 при ω>0; пассивность — антиэрмитова часть
  (χ−χ†)/(2i) положительно полуопределена. `passivity_margin` возвращает min собственное значение, нормированное на max|χ|.
* Линейный отклик M1 = χ H1, H1 — малое приложенное (внешнее) поле. `kind='external'` (по умолчанию): динамическое
  размагничивание включено через N → χ_ext (свойство материала И формы). `kind='internal'`: M1 = χ_int (H1 − N M1),
  χ_int = χ_ext (I − N χ_ext)⁻¹, χ_ext = χ_int (I + N χ_int)⁻¹.
* **Проницаемости.** `mu_r(chi_int)` = I + χ_int — **материальная** μ_r (по умолчанию; `kind='external'` отвергается).
  I + χ_ext зависит от формы: `apparent_mu_shape(chi_ext, shape_label)` возвращает `ApparentMu(mu, shape_label,
  definition)`, подпись формы обязательна. Для однородно намагниченного эллипсоида корректная кажущаяся величина
  ⟨B⟩/(μ0H_app) = **I + (I − N)χ_ext** = (I + χ_int)(I − Nχ_ext) — `apparent_mu_ellipsoid(chi_ext, N, label)` (для сферы
  I + (2/3)χ_ext, а не I + χ_ext).
* Уравнение: [iω(I−αR) + γRW] δ = γR h, R = [[0,−1],[1,0]], χ = μ0 Ms E A Eᵀ. Тензор имеет ранг 2 (нет линейного
  отклика вдоль m0), возвращается в кристаллической системе.
* Закрытая форма для сферы (тест): χ_xx = (μ0Ms/2)γ[1/(γB−ω(1+iα)) + 1/(γB+ω(1−iα))]; статика χ(0)=μ0Ms/B.
* Крамерс–Кронинг: `kramers_kronig_real` (χ′ из χ″ на неравномерной положительной сетке, вычитание особенности,
  O(n²)); точность ограничена шириной сетки и усечением хвоста — тест с допуском 2%, достигнуто 4·10⁻⁴.

## 6. Поликристалл (`polycrystal.py`)

* Уровни результата: `ideal_crystal`, `grain_ensemble_noninteracting` (поле `level`).
* Зерно с поворотом R (v_lab = R v_cryst): B_c = RᵀB, N_c = RᵀN_lab R, χ_lab = R χ_c Rᵀ. Текстура Марча–Долласа
  w ∝ (r² cos²ψ + sin²ψ/r)^−3/2 (r — входной параметр; r<1 → c вдоль оси текстуры; r=1 — изотропно).
* Состояние зерна: `global` (глобальный минимум, вырожденные усредняются) или `field_aligned` (релаксация от
  направления поля — историческая ветвь).

### 6.1 Режимы размагничивания (`demag=`)

| режим | что делает | результат |
|---|---|---|
| **`macro_meanfield`** (по умолчанию) | зёрна без собственной формы (`N_grain` = `no_shape()` = 0, либо задаётся явно); форма образца `N_sample` (в лабораторной системе; по умолчанию `N_lab`, иначе `model.N`) действует через макроскопическое поле **B_int = B_app − μ0 Ms N_sample ⟨m⟩**, решаемое самосогласованно (итерации с демпфированием, допуск `macro_tol_T`=1e-7 Т, `macro_maxit`=80; для `global` состояния зёрен переотбираются на найденном поле). Динамика усредняется как **χ_int** | `kind='internal'`, `chi_lab = chi_int_lab = ⟨χ_int⟩`; дополнительно `chi_ext_lab = χ_int(I+N_sample χ_int)⁻¹`, `B_int_lab`, `M_avg_A_per_m`, `converged`, `n_iter`; при `kind='external'` в `chi_lab` кладётся `chi_ext_lab` |
| `per_grain` | каждому зерну приписана форма образца (`N_grain` или `N_sample`), как у изолированной частицы | `physically_invalid_for_bulk=True`, `UserWarning`, запись в `notes`; `kind='external'` |

Если итерации не сошлись, в `notes` — `NOT converged`, `converged=False` и `RuntimeWarning`: результат ненадёжен.
История (гистерезис) не моделируется: ветвь `global` — равновесное состояние при найденном B_int.

### 6.2 Усреднение по ориентациям

* **Азимут кристалла вокруг c** обязателен при K4 ≠ 0 (член cos6φ). Раньше при `n_phi=1` у всех зёрен азимут был 0, и
  результат отличался от истинного на десятки процентов (проба p5: ≈29%). Теперь:
  * `quadrature='auto'`: если поле, `N_sample`, `N_grain` и текстура осесимметричны относительно общей оси (поворот
    оси c вокруг неё — симметрия), применяется **квадратура Гаусса–Лежандра по cosψ** (`n_c` узлов) — точное усреднение
    по долготе; при K4 ≠ 0 это произведение с `n_beta` (12 по умолчанию, ошибка порядка 1% для K4 из пробы p5) равноотстоящими азимутами в одном периоде π/3
    (сходимость по n_beta экспоненциальная: 6→3%, 8→1.6%, 12→0.6%, 24→6e-6 в пробе p5);
  * иначе — `n_c` направлений c (Фибоначчи) с **независимыми квазислучайными азимутами** (кронекеровская
    последовательность с иррациональным шагом, не совпадающим с долготным шагом Фибоначчи) — `orientation_grid`,
    `quasi_azimuths`. При K4 ≠ 0 и числе различных азимутов по модулю π/3 менее `min_azimuths` (24; для квадратуры — 6)
    выдаётся `RuntimeWarning` и запись в `notes` (`azimuth='zero'` воспроизводит прежнее поведение).
* Проба p5 (K1=−1.2e5, K2=1e4, K4=−8e3, сфера, B=0.3 Т ∥ z, α=0.02): квадратура Гаусса–Лежандра сходится монотонно по
  n_c (12 → 25 → 50 узлов: 4.7% → 0.9% → 0.6% относительно эталона n_c=400, n_beta=24; остаток 0.6% — ошибка по n_beta=12 в
  тех прогонах, при n_beta=24 она ~1e-5); случайные ориентации (n_c=1600) — в пределах 1–3%, не монотонно (статистический шум).
* **Малое затухание.** При α ≲ 0.02 конечная выборка зёрен даёт «гребёнку» резонансов: расстояние между соседними
  резонансными частотами должно быть заметно меньше α·f. Нужна густая сетка (сотни узлов Гаусса–Лежандра или тысячи
  случайных ориентаций) и проверка сходимости по n_c. Сглаживание через распределение резонансных частот не реализовано.
* Эффективная среда (Брюггеман, Максвелл-Гарнетт) и пористость по Шлёману — **не реализованы**: `effective_medium_mixing`,
  `schloemann_porosity_linewidth`, `porosity_correction`, `intergranular_interaction` возвращают
  `NotImplementedResult(status='not_implemented', value=NotImplemented)`, чисел не выдают.

## 7. Ширина линии (`linewidth.py`)

* Три разные позиции: `mode_x` (собственная мода из модели, задаётся вызывающим), `peak_x` (максимум спектра,
  параболическая интерполяция), `center_half_max` (середина интервала полувысоты).
* Статусы `fwhm`: `valid`, `left_censored`, `right_censored`, `multipeak`, `insufficient_resolution`; дополнительно
  `both_censored` и `no_peak`. Приоритет: цензурирование > multipeak > разрешение > valid. Край сетки не
  подставляется; `width` задан только при `valid` (для `insufficient_resolution` — `width_estimate`).
* **Шум.** Оценка σ белого шума — по MAD второй разности (`noise_sigma`; var(Δ²y)=6σ²). Максимум зашумлённой линии
  смещён вверх, поэтому при σ/max > 2e-3 (`smooth='auto'`) применяется фильтр Савицкого–Голея (кубический, окно ≈ FWHM/4
  отсчётов); окно и σ возвращаются в результате. Пик значим, если prominence ≥ max(`prominence_rel`·max, 5σ) и он не ближе
  `min_separation` (по умолчанию 3 отсчёта) — шумовые выбросы на вершине линии не дают ложный `multipeak`. Лоренциан с 3%
  шумом: `valid`, ширина в пределах 3–5% (25–60 реализаций).
* multipeak: другой значимый максимум с высотой ≥ полувысоты главного.
* **`asymmetric_possible_doublet`** (флаг в результате и запись в `notes`, статус остаётся `valid`): |center_half_max −
  peak_x| > 10% ширины — несимметричная линия или неразрешённый дублет. Симметричный неразрешённый дублет этим тестом не
  обнаруживается.
* Разрешение: минимум 5 узлов внутри интервала полувысоты (`min_points`).
* Расширение: `expand(x_min, x_max) -> (x, y)`; цензурированная сторона расширяется на (k−1)·span, до `max_expand`
  раз и в пределах `x_limits`; иначе остаётся статус.
* `derivative_peak_to_peak`: расстояние между экстремумами dy/dx (ΔH_pp), цензурирование по краю сетки. Чистые данные —
  прямое дифференцирование. При шуме (σ/max > 1e-3) сглаживание СГ с двумя окнами (w≈FWHM/4 и 2w+1); если два Δpp
  различаются более чем на `stability_tol`=10% — статус **`noisy_unreliable`**, значение не выдаётся (обе оценки в
  `estimates`). Валидное значение при шуме имеет точность порядка 10–15% (проверено на лоренциане с шумом 0.3–1%).
  Только для лоренциана FWHM = √3·ΔH_pp (`lorentzian_fwhm_from_dpp`); гауссиан даёт 1.177 — общей связи нет.
* `width_freq_to_field` / `width_field_to_freq`: Δ(μ0H) = Δf/|df/dB|. Предупреждения о применимости (жёсткий сдвиг
  по ветви с локально постоянным наклоном); точный нуль наклона → `slope_zero`; **|df/dB| ≤ max(slope_tol, slope_floor)**
  (пол 1 МГц/Тл, действует и при `slope_tol=0`) → `slope_too_small` без значения (вблизи точки поворота ветви преобразование
  расходится); при изменении наклона >10% по линии (задана кривизна) — предупреждение.

## 8. Неопределённость (`uncertainty.py`)

`monte_carlo(func, distributions|sampler, n, seed)`: последовательный прогон; распределения извне (scipy frozen,
callable(rng), число). Медиана и интервал (по умолчанию 2.5–97.5%) по ВАЛИДНЫМ выборкам; None/NaN/исключения
считаются в `failures`, не подставляются; значения `numpy.integer` / `numpy.floating` принимаются как числа. Pool не
используется; позже — через `hexw.util.pool`.

## 9. Ограничения

* Макроспин: однородная прецессия, одна мода на состояние; нет обменных/магнитостатических спин-волновых мод,
  нет доменной структуры, нет температурной зависимости параметров.
* Анизотропия: только перечисленные члены; нет базисной анизотропии 12-го порядка и т.п.
* Гильберт-затухание только; α не зависит от частоты и состояния; нет неоднородного уширения (его в спектр вносит
  ансамбль зёрен).
* Ансамбль зёрен — невзаимодействующий; макроскопическое размагничивание — среднее поле (однородный эллипсоид), без
  локальных полей Лоренца, пористости и межзёренных взаимодействий; нет гистерезиса в `macro_meanfield`.
* Поиск минимумов эвристический (релаксация из каждой точки сетки + контроль на удвоенной сетке): минимум с бассейном
  уже шага сетки может быть пропущен — тогда это видно только при изменении числа минимумов на удвоенной сетке
  (`possibly_incomplete`).
* `H_res` — сканирование с уточнением экстремумов и спинодалей; полнота гарантируется только в пределах разрешения
  `n_points`, `n_grid`, `coarse_step` (статус `possibly_incomplete` — эвристика, не доказательство).
