W-type hexaferrites · local research model

От состава к магнитному отклику

Структурные гипотезы, ФМР и электромагнитные параметры. Расчёт по литературной модели и отдельная проверка экспериментом.

Исследовательская версия. Погрешность ≤10% пока не подтверждена. Полосы на графиках показывают разброс сценариев модели. Для Mn/Mg/Ni используются данные первичного рисунка по стронциевым монокристаллам; вне изученных составов и температур неопределённость увеличивается.

Новый прогноз

Кнопка заполняет поля. Для запуска проверьте их и нажмите «Рассчитать».

Диэлектрические параметры и пористость

Необязательный JSON: dielectric_model с epsilon_inf, relaxations, sigma_dc_S_m и provenance; porosity_fraction. Без этих данных ε не прогнозируется. Пористость: изотропное приближение сферических пор.

Одна задача за раз, пониженный приоритет. Большой расчёт может занять несколько минут. Прогресс сохраняется после каждой точки поля.

Что выдаёт модель

Кандидаты структуры и заселённости узлов, Mₛ(T), T꜀, K₁…K₄, равновесные состояния, собственные частоты, спектры χ и тензор μ.

Текущий прогноз по формуле описывает однородный магнитный режим. Оптические обменные моды доступны отдельному модулю при явном задании обменных параметров. Геометрия кандидатов взята из литературного шаблона, без релаксации каждого состава.

Первый запуск

Пример: SrCoZnFe₁₆O₂₇, 300 K, поля 0 / 0.4 / 0.8 Тл, частоты 0.1–100 ГГц. После завершения откройте результат в списке задач ниже.

Форма «сфера», g = 2 и α = 0.02 — заданные условия учебного сценария.

Обработать измерение

Сначала зафиксируйте выбранный прогноз во вкладке «Проверка модели».

Без калибровки будет сохранён график по каналам. Для SPC сначала должны быть проверены свёртка и линейность шкалы.

Дополнительные параметры для специалиста

Необходимые условия

РФА: .mdi или таблица 2θ/интенсивность, длина волны. Здесь доступны поиск пиков и первичная проверка структуры; полный Ритвельд требует отдельного проекта GSAS-II.

Мёссбауэр: .spc или скорость/счёт; подтверждённая калибровка α-Fe. Без неё сохраняется график по каналам.

РЭМ: изображение и масштаб um_per_pixel; обрежьте подписи и масштабную линейку. Маску и наложение нужно просмотреть.

EDS: CSV с колонками element, weight_percent, необязательно std_weight_percent. Нужен уже количественно обработанный экспорт прибора.

ФМР: таблица ось/сигнал, axis_unit, signal_kind: absorption или derivative; baseline.

Обработка эксперимента не изменяет теоретические параметры.

Зафиксировать и проверить

Фиксация проверяет код, литературные данные и контрольные суммы результатов. При изменении модели нужно выполнить новый прогноз.

Сравниваются одинаковые величины

Собственная частота и максимум поглощения имеют разные определения. Ширина производной не заменяет ширину поглощения.

Состав, температура, поле, единицы и остальные условия должны совпадать. Прежнее использование данных сохраняется в статусе проверки.

PASS означает выполнение критерия для одной указанной величины. Это не подтверждает точность всей модели.

Как включить программу

Откройте папку C:\MIPT\working_stuff\Hexx и дважды нажмите START_HEXW.cmd. Затем откройте http://127.0.0.1:8765/ в браузере. Если программа уже работает, повторный запуск не нужен.

Служебное окно запуска оставьте открытым, пока работаете. Ничего вводить в нём не нужно.

Первый расчёт за пять действий

  1. Откройте вкладку «Расчёт».
  2. Нажмите «Заполнить пример Co–Zn». Пока оставьте все заполненные значения.
  3. Нажмите «Рассчитать» один раз.
  4. В блоке «Задачи» дождитесь надписи «Готово».
  5. Нажмите «Открыть результат». Появятся таблица и графики.

Для следующего образца измените формулу, название и условия. Число точек задаёт, сколько значений внутри диапазона будет рассчитано.

Где смотреть ответ

Таблица показывает рассчитанную частоту для каждого поля. График помогает увидеть её изменение. Полоса около линии показывает разброс прогноза. Спектры находятся ниже.

В разделе «Таблицы и файлы результата» можно открыть рисунки и таблицы для сохранения. Уже выполненные работы находятся во вкладке «Результаты»: последние — сверху. Предыдущие версии можно включить флажком.

Это исследовательская программа. Точность ФМР до 10% пока не подтверждена. Полученное число является расчётной оценкой.

Как обработать своё измерение

  1. После прогноза откройте «Проверка модели», выберите его и нажмите «Зафиксировать этот прогноз».
  2. Перейдите в «Анализ данных» и выберите вид измерения.
  3. Вставьте полный путь к файлу. Его можно получить в Проводнике через «Копировать как путь».
  4. Заполните поля выбранного метода и нажмите «Обработать».
  5. Откройте результат в блоке задач или в списке обработанных измерений.

Для РФА нужна длина волны, для РЭМ — масштаб изображения, для физических параметров Мёссбауэра — калибровка. Первое сравнение с теорией лучше подготовить вместе с коллегой: для него требуется отдельный файл с измеренными значениями.

Где всё хранится

Вся рабочая папка — C:\MIPT\working_stuff\Hexx. Инструкция: GUIDE/USER_GUIDE_HEXW_RU.md. Полученные результаты: runs. Сохранённые исходные измерения: vault/lab_validation. Для обычной работы остальные папки открывать не требуется.

Результаты сохраняются автоматически. После перезапуска программы они останутся во вкладке «Результаты».
