# CONFLICTS (fit) - противоречия и методические различия в данных fit-выборки

Это редакция для теории (`literature/fit/`): только источники и образцы, входящие в fit по `SPLIT_DECISION.md`
(L02, L01 Mg и Ni, L05, L03, C004, L11). Сравнения с holdout-образцами и holdout-публикациями (L01 Co/Zn, C023, C015,
L12, C057, C060, C044, C056, C036, C052, C066) сюда **не входят**; полная смешанная версия лежит в защищённой зоне
`literature_holdout/_original_mixed/CONFLICTS.md` и недоступна коду теории.

Принцип (ТЗ §4): альтернативы сохранены в `records_fit.yaml` как отдельные записи; усреднения нет.
Обозначения: x_tot = число A (Co/Zn/Mn) на ф.у.

## B. Внутренние расхождения одной статьи
1. **L01, Ms (Mg, Ni)**: Ms даётся в двух видах - сырой VSM (60.3 / 67.7 A m2/kg для Mg / Ni) и скорректированный по литературным Ms примесных фаз (63.7 / 69.0 A m2/kg). Это одно измерение с разной обработкой (`measurement_group` общая); использовать вместе нельзя. Ms из нейтронных моментов существенно ниже (авторы объясняют различием "двух зондов") и зависит от ограничений на моменты: не использовать как эталон Ms.
2. **L02, abstract vs Table 3**: T_C(Co2) 780 K (abstract) против 790 K (таблица); T_C(CoZn) 680 против 700 K; переход 520/360 K (текст, "onset") против 555/405 K (таблица, максимум производной) - разные определения; при сравнении с M(T) нужен выбор определения (T_SR из максимума производной или из начала).
3. **L02, Table S3 (SrZn2W)**: для Fe4 (W4, 4f_VI oct S) напечатан Mz = -3.554(13), тогда как .mcif даёт Fe4 тот же знак, что 6g/12k/2d (группа "вверх", величина 0.1089 x 32.829 = 3.575 muB). Из остальных строк ясно: W4 должен быть "вверх". Сохранено как напечатано + пометка.
4. **L02, mCIF**: числа в `_magnetic_atom_site_moment_crystalaxis_*` равны моменту (muB) / длина ячейки (A); умножение на длину оси воспроизводит Table S1-S3. Не интерпретировать как muB напрямую.
5. **L01, Table S1-S3 и CIF**: отдельные цифры в тексте SI искажены извлечением (PDF layout); использованы CIF и рендер страницы.

## C. Намагниченность и анизотропия: определения
Ms Sr (L01, 300 K, A m2/kg = emu/g; raw / corrected): Mg 60.3 / 63.7, Ni 67.7 / 69.0; Sr Fe2W (C004, герметизированная трубка, SrFe18O27): 81.0-81.1.
Ba-аналог (L11, 300 K; перенос Ba -> Sr, tier 3): Co 74.90, Ni 69.49, Zn 72.90, Mn 47.77 (нехарактерно низко, Mn-W на воздухе), Fe2W 95.34 (подозрительно выше всех: L05 приводит ~78 A m2/kg для BaFe18O27 из Lotgering; оставлено как есть, но без использования в fit).
Сравнение Ba и Sr не доказывает переносимость (разные синтезы, определения Ms, примеси).

**Анизотропия** (определения РАЗНЫЕ, не сравнивать напрямую):
- L05 (DFT, 0 K): Ku = 0.148 MJ/m3 (SrW), mu0Ha = 2Ku/Ms = 0.569 T; "эксперимент" Ku = 0.344 MJ/m3 при 300 K - вторичная цитата (Ueda, ссылка [65]), в корпус не входит (`excluded_secondary`).
- C004: "магнитная анизотропия SrW при RT 1.30-1.55 MA/m" (refs 5-7; величина не определена, вероятно HA в A/m) = 1.63-1.95 T как mu0H - в 2.9-3.4 раза больше DFT mu0Ha и в ~1.2-1.5 раз больше mu0Ha, пересчитанного из Ku(exp) (2 x 0.344e6 / 5.19e5 = 1.33 T).
- L11 (Ba, 300 K): Ha = 13739.57 Oe (Fe2W, N2), 12206.23 (Zn), 11301.48 (Mn), 10750.90 (Co), 10700.60 (Ni) - из коэффициента 1/H2 закона приближения (B = Ha^2/15 = 4K1^2/(15 Ms^2), только K1, одноосный); для Co2W (планарный) формально. 13739.57 Oe = 1.374 T как mu0H = 1.093 MA/m.
Следствие: прямых данных по K1/K2/HA для Sr Co/Zn/Mn в fit **нет**; DFT (L05) для чистой SrFe18O27 занижает ~2x относительно приведённого эксперимента.

## D. Магнитная структура и переходы (L02)
L02: Cm'cm' планарная + неколлинеарные моды (RT); M(T): TT 555 K (производная) / 520 K (onset); T_C 790 K (100 Oe).
Планарно-осевая граница по составу при RT: L02 экстраполяция SrCo0.65Zn1.35 (x_Co = 0.65). Наклон dT_SR/dx_Co: Sr (L02 Table 3, TT по производной) 265 K (x_Co = 0.5) -> 405 K (1.0): ~280 K на единицу x_Co. Планарно-осевой переход трактуется как "конус -> ось" без прямой проверки: не решать до температурной дифракции или DFT.

## E. Состав и валентность
- L03: фактический состав W-фазы SrMe(2-d)Fe(16+d)O27, Sr:(Fe+Me) = 1:18; в воздухе Me < 2 (порядок отклонения Co < Ni < Zn < Mg); при 387 atm O2 n*(Co) = 2.03, n*(Ni) = 1.93, у Zn/Mg идеал не достигается; монокристалл Co2W (флюс) - 1.79 Co в W-фазе. L02: Co 1.71(3), Zn 1.799(11). L01 (Ni): 2.1(1) - выше 2.
- Условная модель n(Fe2+) = 2 - x_A (ТЗ §7) выполнена лишь для части выборок (`structures/composition_charge_check.csv`: L01-Ni -0.113 - отрицательное => нужны Fe4+/Co3+/дефекты кислорода или ошибка уточнения).

## F. Допущения авторов о моментах (не использовать как параметры)
- L11: Mn2+ = 2.7 muB, Co2+ = 4.0, Ni2+ = 3.0 muB (против Fe3+ 5 muB). Для высокоспинового Mn2+ ожидается ~5 muB. L01/L02: Fe3+:Co2+ = 5:3 (орбитальный вклад пренебрежён). Mn-запись L11 помечена assumed_by_authors.
- L05: сумма моментов в PAW-сферах по таблице 2 (~48.9 muB на ячейку) != m_tot = 54.99 muB: интерстициальные/O вклады; ожидаемый расчётный Ms = 0.652 T.
- Моменты по позициям: L01 (Fig. 4) даёт значения, усреднённые по заполнению (диамагнитные ионы входят как нули), L02 (Tables S1-S3) - момент Fe. Определения различны (`moment_definition`) - не смешивать и не сравнивать без явного пересчёта.

## G. Методические различия
- Ms: L01 - экстраполяция по приближению к насыщению плюс графическая коррекция размагничивания (3 T, порошок в капсуле); C004 - экстраполяция 1/H2 для свободных частиц ~100 um до 6.4 MA/m; L11 - линейная подгонка 1/H2, +-30 kOe.
- T_C: ТГ в магнитном поле (L01, пересечение касательных), производная M(T) (L02), минимум dM/dT.
- Cu Ka1 / Co Ka / нейтронные длины волн отличаются - не влияет на параметры, но влияет на чувствительность к Fe/Co/Zn (контраст).
