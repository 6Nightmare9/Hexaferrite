# Возможность собственных DFT-расчётов W-гексаферритов на ноутбуке

Железо: Ryzen 7 7735H (8C/16T), 15.2 ГБ RAM, Windows 11, без admin. Энергии пилотов -- только оценка ресурсов.

## 1. Движки
| Движок | Статус |
|---|---|
| QE 7.6, MSYS2 UCRT64 (serial + OpenMP, без MPI) | выбран, установлен, работает; DFT+U (Dudarev), nspin=2; код поддерживает noncollinear/SOC (SOC не запускался) |
| QE с нативным MPI на Windows | готовой сборки нет |
| GPAW / CP2K / SIESTA / ABINIT (conda-forge, pip) | на win-64 пригодных готовых сборок нет; не ставились |
| QE в WSL2 + OpenMPI | нужен admin, см. раздел 6 |

Особенность: OpenMP-потоки в этой сборке замедляют, BLAS-потоки не помогают, поэтому 1 поток на процесс;
масштабирование только запуском нескольких независимых процессов.

Пилот c в прошлом запуске был только подготовлен; здесь измерен. FFT: 60x60x320, 420k G-векторов.
Параллельный throughput (пилот a, 14 k, одиночный прогон 102 с): 4 процесса одновременно -- по ~128 с (ускорение 3.2x);
8 процессов -- по ~170 с (4.8x). Для W ограничение -- память: 3.3 ГБ на процесс, т.е. не более 3 параллельно (~10 ГБ).
Масштабирование M -> W (64 -> 92 атома): 79 -> ~290 с/ит (x3.7), согласуется с ~N^2.5-3.

## 3. Экстраполяция на W (92 ат.) -- оценка, кроме измеренной итерации
Допущения: Γ-только, ~30 SCF-итераций из хорошего старта (с нуля для АФМ-конфигураций 40-60), ~290 с/итерацию.
Для сетки 2x2x1 стоимость ещё ~3x.
| Задача | Оценка (1 процесс) |
|---|---|
| Коллинеарный SCF, Γ | ~2.5-3 ч, 3.3 ГБ (2x2x1: ~8-10 ч) |
| Релаксация ионов (10-15 шагов BFGS, ~12 ит. на шаг) | ~10-15 ч на Γ; не рекомендуется, брать экспериментальную геометрию |
| SOC, неколлинеарный, одно направление (Γ) | стоимость x3-4, RAM ~6-8 ГБ, без симметрии: ~7-10 ч на SCF; MAE (мкэВ-мэВ) на Γ-сетке не сходится, нужна плотная сетка -> десятки часов на направление |
| Конфигурации для J | ниже |

Конфигурации для J: 7 подрешёток; независимых Fe-Fe обменов ~10-14, нужно не меньше N_J+1, т.е. ~12-16 коллинеарных
конфигураций (из 2^7/2 = 64 возможных переворотов подрешёток; внутриподрешёточные J потребовали бы суперъячейку -- на 92 атомах нереально).
Число N_J здесь оценочное, список пар по структуре не строился.
Кампания J для одной композиции (Γ): 14 x ~3.5 ч = ~50 ч CPU; на 3 параллельных процессах ~17-20 ч wall; с 2x2x1 ~60 ч wall.
Каждый допант/позиция замещения умножает это число. Потрачено на пилоты за оба запуска порядка 1.5 ч.

## 4. Вывод
- Реально: коллинеарный DFT+U SCF W (92 ат.) ~3 ч на конфигурацию на Γ; набор ~14 конфигураций для J одной композиции за ~1 сутки wall;
  M-тип (64 ат.) в 3-4 раза быстрее (~40 мин на SCF на Γ), годится для калибровки U и методики.
- Нереально разумно: релаксация 92-атомной ячейки, SOC-анизотропия со сходимостью по k, суперъячейки, десятки композиций.
- Γ-только на ячейке 5.9 Å с U=4 эВ даёт систематическую погрешность; нужна проверка 2x2x1 на 2-3 конфигурациях.

## 5. Рекомендация
Считать на ноутбуке: калибровку U/методики (гематит, M-тип); коллинеарные конфигурации для J у W-SrFe18O27 и 1-2 ключевых
допированных составов по экспериментальной геометрии без релаксации; локальные моменты и знаки главных J.
Брать из литературы: константы анизотропии/SOC, релаксированные геометрии, J для широкого списка допантов (Co, Mn), абсолютные Tc;
расчёты использовать как проверку согласованности литературных J.

## 6. Что дал бы admin (WSL2)
QE + OpenMPI в WSL2: настоящий MPI (k-точки/зоны на 8 ядер) вместо независимых процессов и Linux-BLAS без проблем libgomp.
Оценка (не измерялась): один SCF W на 8 ядрах ускоряется ~5-7x вместо одного процесса, то есть ~30-40 мин на SCF;
SOC SCF становится ~1.5-2 ч, релаксация ~1-2 сут. Общий выигрыш по throughput кампании ~2x, качественно -- доступны SOC и релаксация.
GPU (RTX 4060 8 ГБ): QE-GPU требует Linux и NVHPC, 8 ГБ мало для 92-атомного спин-поляризованного расчёта, fp64 слабый -- выигрыш сомнителен.
