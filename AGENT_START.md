# Вход для ИИ-агента коллеги

Продолжи существующий проект HexW. Сначала полностью прочитай [отчёт передачи](GUIDE/ОТЧЁТ_ДЛЯ_ИИ_АГЕНТА.md), затем указанные в нём ТЗ и протоколы. Не начинай реализацию заново. Проверь установку, Git LFS, доступность прежних результатов и совместимость среды. Отделяй реализованное от экспериментально подтверждённого. Новые изменения делай в отдельной ветке с проверками и контрольной точкой. Научную задачу для следующего этапа согласуй с коллегой, который передал тебе проект.
