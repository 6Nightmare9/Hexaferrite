# split_proposal - предложение разбиения literature_fit / literature_holdout

**Это вариант для вашего решения, а не фиксация.** В `records.yaml` поле `ext.split` и `estimate.source_role` заполнены по этому варианту (вариант A); смена варианта - правка `CLUSTER_SPLIT` в `scripts/rc.py` и пересборка (`scripts/build_records.py`).

## Принципы (ТЗ §4, §13)
1. Делим по **публикациям и химическим сериям**, никогда по точкам. Единица разбиения - кластер (`ext.split_cluster`).
2. Таблица, рисунок и CIF одного измерения (`ext.measurement_group`) - в одном кластере и в одной выборке (L01: CIF + Fig. 3 + Fig. 4 + Table S4 на образец; L02: CIF + Tables S1-S3 + Table 2).
3. Повторно опубликованные/цитируемые значения (C004 intro, L05 "Expt.", C044 "SrCo2W 74.31", C015 intro, C023 cone) - `excluded_secondary_citation`: не входят ни в fit, ни в holdout, пока не найден первоисточник.
4. Ba-данные (tier 3) **не** используются для fit без обоснования переноса: они служат holdout для проверки гипотезы "Ba -> Sr" (с расширенной неопределённостью).
5. DFT из литературы (L05, `status=calculated`) - это не наш DFT (`source_role=dft` зарезервирован под него): здесь он идёт как физический prior в fit.
6. Низкокачественные/внутренне противоречивые (C053) исключены.

## Вариант B (рекомендуется для оценки обобщения)
Leave-one-cluster-out: по очереди скрывать MORCH_L02, MORCH_L01 (Mg+Ni+Co+Zn как один кластер), ISLAM_L05, NAKAI, затем весь Ba-блок. Для каждой скрытой группы - прогноз по параметрам, обученным на остальных; отчёт: интервал и фактическая ошибка (ТЗ §13).

## Вариант C (если нужны независимые Sr-данные в holdout)
Сейчас независимых (другая группа) Sr Co/Zn данных в корпусе почти нет: C023 (одна температура), C015 (композит). Поэтому:
- держите **L01-Co/Zn как holdout между партиями**, а L02 как fit (вариант A), либо наоборот (поменять - равноправно);
- независимый Sr holdout появится после снятия недоступных первоисточников (C011/C019/C020/C022 "Zn/Co-Sr W" - closed-access, L04) или собственного DFT (`source_role=dft`) как кросс-проверки;
- для Mn в Sr нет ничего: holdout невозможен (только DFT-ограничения и Ba-аналог L11).

## Что нельзя делить
- точки одной кривой (M(T), Fig. 4 L02), позиции одной структуры, значения Ms/T_C одного образца;
- raw/corrected Ms L01 (`Ms_VSM_raw`, `Ms_VSM_impurity_corrected`) - одно измерение;
- Table 3 L02 и abstract L02 (T_C 780/790 K) - одно измерение;
- L01 CIF-заселённости и Fig. 3 (одна рефайнмент-группа).

## Предупреждения о "утечке"
- L01/L02 перекрываются номинальными составами и одной группой авторов. При fit на L02 и holdout на L01 ошибка, скорее всего, **оптимистична**.
- Значения Ba->Sr как holdout проверяют не модель структуры, а допущение переноса; успех не доказывает его для Mn.
- Любое использование наших лабораторных данных (vault) для выбора варианта запрещено - выбор делается только по этому файлу и литературе.
