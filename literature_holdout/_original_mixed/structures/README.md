# structures/ - сводка по CIF W-фазы (Mørch 2019, Mørch & Christensen 2023)

Источники: `raw/theory_side/06_literature/L01_Morch2019/supporting/lt5018sup_cif/*` (DOI 10.1107/S2052252519003130) и `L02_Morch2023/supporting/CIFs/*` (DOI 10.1107/S1600576723002133). Разбор: pymatgen (`parse_cifs.py`, `build_site_coordinates.py`), сверка с текстом статей и SI (Table S4, S1-S3, Fig. 3).

**Предупреждение (ТЗ §7).** Все CIF - частично заселённые усреднённые модели (Fe/Co/Zn/Mg/Ni на одной позиции с дробными заселённостями; W7 = половинная заселённость расщеплённой 4f). Это **не** конфигурации для DFT. Для DFT нужно перечислять симметрийно неэквивалентные упорядочения с целыми числами атомов и зарядовой нейтральностью (см. `composition_charge_check.csv`).
