## B. Внутренние расхождения одной статьи
1. **L01, Fig. 3 против CIF/Table S3 (Sr-Zn2W)**: Zn на 4f_IV tet(S) 10.5(8) % (Fig. 3) против 0.236(9) (CIF и Table S3); 4f_VI(R): 0 % против 0.032(8). Сумма Zn на ф.е. 1.90 достигается только со значениями CIF (1.108 + 0.472 + 0.056 + 0.21 + 0.064 = 1.91); значения Fig. 3 дали бы 1.58. Сохранены обе версии (`site_occupancy_Zn_W2_FIG3_alt`, `..._W6_FIG3_alt`).
2. **L01, Ms**: основной текст (раздел 3.4) называет 78.5 A m2/kg (Co) наибольшим; в заключении "Ms,VSM" дано 80.4 (Zn) > 78.4 (Co) - это значения, скорректированные по литературным Ms примесей. Raw VSM: 60.3 / 78.5 / 67.7 / 76.2; скорректированные: 63.7 / 78.4 / 69.0 / 80.4 (A m2/kg, Mg/Co/Ni/Zn). Ms из нейтронных моментов (41-59) существенно ниже (авторы: различие "двух зондов"); при равных моментах на всех позициях - 71.7-93.6 (Table S9): Ms_NPD зависит от ограничений, не использовать как эталон Ms.
3. **L02, abstract vs Table 3**: T_C(Co2) 780 K (abstract) против 790 K (таблица); T_C(CoZn) 680 против 700 K; переход 520/360 K (текст, "onset") против 555/405 K (таблица, максимум производной) - разные определения; нужны обе, выбор определения нужен при сравнении с нашим M(T) (T_SR из максимума производной или начала).
4. **L02, Table S3 (SrZn2W)**: для Fe4 (W4, 4f_VI oct S) напечатан Mz = -3.554(13), тогда как .mcif даёт Fe4 тот же знак, что 6g/12k/2d (группа "вверх", величина 0.1089 x 32.829 = 3.575 muB). Из остальных строк ясно: W4 должен быть "вверх". Сохранено как напечатано + пометка.
5. **L02, mCIF**: числа в `_magnetic_atom_site_moment_crystalaxis_*` равны моменту (muB) / длина ячейки (A); умножение на длину оси воспроизводит Table S1-S3 (проверено для Zn). Не интерпретировать как muB напрямую.
6. **L01 Table S1-S3 и CIF**: отдельные цифры в тексте SI искажены извлечением (PDF layout); использованы CIF и рендер страницы.

## C. Намагниченность и анизотропия: Ba против Sr, определения
Сравнение (A m2/kg = emu/g, 300 K; derived_by_us): 

| A | Sr (L01, raw / corr.) | Ba |
|---|---|---|
| Mg | 60.3 / 63.7 | 59.44 (C044, BaMg2W, 1300 C) |
| Co | 78.5 / 78.4 | 74.90 (L11), 73.1 (C036), 72.56 (C044) |
| Ni | 67.7 / 69.0 | 69.49 (L11) |
| Zn | 76.2 / 80.4 | 72.90 (L11) |
| Mn | нет | 47.77 (L11; нехарактерно низко, Mn-W на воздухе) |
| Fe (Fe2W) | 81.0-81.1 (C004, герметизированная трубка, SrFe18O27) | 95.34 (L11, N2; значение подозрительно выше всех - сравнить: Ms(Fe2W,Ba) литературные 78 при RT по ссылкам L05) |

Вывод: Sr-W выше Ba-аналогов на ~3-6 A m2/kg для Co/Zn, практически равны для Mg (+0.9) и Ni (-1.8); это не доказывает переносимость (разные синтезы, определения Ms, примеси); значение 95.34 (L11 Fe2W) подозрительно (L05 приводит ~78 A m2/kg для BaFe18O27 из Lotgering), оставлено как есть, но без использования в fit.

**Анизотропия** (определения РАЗНЫЕ, не сравнивать напрямую):
- L05 (DFT, 0 K): Ku = 0.148 MJ/m3 (SrW), mu0Ha = 2Ku/Ms = 0.569 T; "эксперимент" Ku = 0.344 MJ/m3 при 300 K - вторичная цитата (Ueda, ссылка [65]), в корпус не входит -> не используется как holdout.
- C004: "магнитная анизотропия SrW при RT 1.30-1.55 MA/m" (refs 5-7; величина не определена, вероятно HA в A/m) = 1.63-1.95 T как mu0H - в 2.9-3.4 раза больше DFT mu0Ha и в ~1.2-1.5 раз больше mu0Ha, пересчитанного из Ku(exp) (2 x 0.344e6 / 5.19e5 = 1.33 T).
- L11 (Ba, 300 K): Ha = 13739.57 Oe (Fe2W, N2), 12206.23 (Zn), 11301.48 (Mn), 10750.90 (Co), 10700.60 (Ni) - из коэффициента 1/H2 закона приближения (B = Ha^2/15 = 4K1^2/(15 Ms^2), только K1, одноосный); для Co2W (планарный) формально. 13739.57 Oe = 1.374 T как mu0H = 1.093 MA/m.
- C057 (Ba Co0.62Zn1.38W, монокристалл, калориметрия): K1 = 8.7e4 J/m3 при 296 K (K2, K3 пренебрежены) - прямое измерение, но другой состав.
Следствие: данных по K1/K2/HA для Sr Co/Zn/Mn **нет**; DFT (L05) для чистой SrFe18O27 занижает ~2x относительно приведённого эксперимента.

Для Sr-Co2W дифракция говорит "планарная при RT", а переход вблизи 470-555 K трактуется как "конус -> ось" без прямой проверки. Не решать до температурной дифракции или DFT.

Планарно-осевая граница по составу при RT: L02 экстраполяция SrCo0.65Zn1.35 (x_Co=0.65); Ba: C060 x_Co=0.7 (T_SR ~280-300 K: chi' max 6 C = 279 K; chi'' min 27 C = 300 K) и 0.8 (~55 C = 328 K); C057 x_Co=0.62 -> 215 K; L12 граница по Zn x=1.3 (x_Co=0.7). Наклон dT_SR/dx_Co: Sr (L02 Table 3, TT производная) 265 K (x_Co=0.5) -> 405 K (1.0): ~280 K на единицу x_Co; Ba (C057 -> C060): (328-215)/(0.8-0.62) ~ 630 K на единицу x_Co (разные методики: калориметрия/ТГ/AC) - разброс 2x, не усреднять.

## E. Состав и валентность
- L03: фактический состав W-фазы SrMe(2-d)Fe(16+d)O27, Sr:(Fe+Me) = 1:18; в воздухе Me < 2 (порядок отклонения Co < Ni < Zn < Mg); при 387 atm O2 n*(Co) = 2.03, n*(Ni) = 1.93, у Zn/Mg идеал не достигается; монокристалл Co2W (флюс) - 1.79 Co в W-фазе. L01: Co 2.2(1), Ni 2.1(1) (выше 2), L02: Co 1.71(3), Zn 1.799(11). Условная модель n(Fe2+) = 2 - x_A (ТЗ §7) выполнена лишь для части выборок (`structures/composition_charge_check.csv`: L01-Co -0.165, L01-Ni -0.113 - отрицательные => нужны Fe4+/Co3+/дефекты кислорода или ошибка уточнения).
- C015: параметры W-фазы в композите a = 5.849 A, c = 33.112 A отличаются от L01/L02 (5.895 A, 32.74-32.76 A) на -0.046 A по a и +0.37 A по c - аномалия (композит W/Z 80:20, нестехиометрия); вес снижен.

## F. Допущения авторов о моментах (не использовать как параметры)
- L11: Mn2+ = 2.7 muB, Co2+ = 4.0, Ni2+ = 3.0 muB (против Fe3+ 5 muB). Для высокоспинового Mn2+ ожидается ~5 muB; C044: Co2+ 3.7 muB; L01/L02: Fe3+:Co2+ = 5:3 (орб. вклад пренебрежён). Mn-запись L11 помечена assumed_by_authors.
- L05: сумма моментов в PAW-сферах по таблице 2 (~48.9 muB на ячейку) != m_tot = 54.99 muB: интерстициальные/O вклады; ожидаемый расчётный Ms = 0.652 T.

## G. Методические различия Ms/HA/T
- Ms: L01 - extrapolation по приближению к насыщению плюс графическая коррекция размагничивания (3 T, порошок в капсуле); C004 - экстраполяция 1/H2 для свободных частиц ~100 um до 6.4 MA/m; L11 - линейная подгонка 1/H2, +-30 kOe; C056 - "Ms" определение не указано; C036/C044 - VSM, определение не указано.
- T_C: ТГ в магнитном поле (L01, пересечение касательных), производная M(T) (L02, C044), минимум dM/dT; Ba C060 - "~430 C" на глаз.
- Cu Kα1/Co Kα/нейтронные длины волн отличаются - не влияет на параметры, но влияет на чувствительность к Fe/Co/Zn (контраст, L01 Ni - неоднозначно).
- FMR/mu(f) по Ba: образцы - композиты с парафином (C056, 8:3 wt) или спечённые тороиды (C036, плотность не указана); ширины/g/alpha не заданы.
