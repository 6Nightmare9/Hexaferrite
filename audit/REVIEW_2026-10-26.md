Что необходимо завершить

Геометрия атомов пока берётся из литературного CIF-шаблона L02; это не завершённый расчёт новой релаксированной структуры для каждого состава.

1. Нет готовой сквозной цепочки «состав → параметры → прогнозы → фиксация → независимая проверка». CLI-команды predict, freeze-model, analyze-exp, validate и resume пока являются заглушками. Наличие библиотечных функций не означает готовность всей программы.
2. experiment, validate и spin пока содержат зарезервированные пространства имён. Полноценные модули обработки РФА, Mössbauer, РЭМ/EDS и многоподрешёточной спиновой динамики ещё предстоит реализовать. Для диэлектрического отклика/проводимости также нет законченного независимого модуля.
3. До независимой проверки требуется завершить фиксацию модели. project/hexw/io/paths.py:is_frozen сейчас проверяет только наличие непустого FROZEN_MODEL.json; привязки к коду, параметрам, корпусу и прогнозам нет. В ValidationStore.append параметр prediction пока необязателен. Файл FROZEN_MODEL.json в полученном проекте отсутствует. Это незавершённый этап, а не выполненная независимая валидация.
4. Большая неопределённость анизотропии: K2/K4 в значительной мере заданы априорными предположениями; размещение Fe2+ для DFT является одной эвристической реализацией; Mn особенно слабо ограничен литературой. В docs/ANISOTROPY_MODEL.md для SrCo2W при одном сценарии указано f=23.5 ГГц с 95%-м интервалом 2.8–225 ГГц. Такой результат не подтверждает точность 10%.
5. Сходимость DFT W-фазы по k-сетке, обрезаниям, U и магнитным/валентным стартам не установлена. Доступный тест гематита не доказывает точность обмена и ФМР W-гексаферрита. Критерий ошибки энергий конфигураций нельзя автоматически переносить на ошибку частот ФМР.
6. В SPLIT_DECISION.md раскрыты инциденты знакомства руководителя с частью будущего литературного holdout. Эти данные нельзя описывать как полностью слепую проверку. Исторические лабораторные данные также требуют учёта prior_use.

Для новой W-кампании сначала нужен завершённый измеренный пилот. Дополнительные платные API и лицензии для текущего Python/QE-пути не требуются.

Порядок продолжения

1. Зафиксировать восстановленный базовый снимок и воспроизводимое окружение; сохранить все незакоммиченные изменения реестра и корпуса.
2. Проверить ключевые литературные источники и уточнить абсолютный масштаб и базисную анизотропию, g, демпфирование; явно отделять литературные значения от допущений.
3. Завершить воспроизводимый сквозной сценарий Co–Zn с совместной неопределённостью и маркировкой области применимости; развивать Mn как отдельные валентные/структурные гипотезы.
4. Доделать freeze/validation, независимые обработчики измерений и сопоставление величин. Старые анализы использовать с раскрытием ретроспективного характера.
5. Выполнять собственные DFT-кампании после локального пилота и проверки их научной необходимости; многоподрешёточную динамику и эффективные электромагнитные свойства подключать поэтапно.

Устранение причин первоначальных сбоев

Служебный манифест переноса и временные тестовые деревья первоначально были размещены аудитором внутри области, сканируемой на ссылки к holdout. Это влияло на проверки аудита; найденные имена не означали передачу экспериментальных значений в физическую модель. Метаданные и исходные журналы перенесены в отдельный защищённый архив, файлы сделаны только для чтения. Новые временные тестовые данные создаются вне дерева модели. Среда перенесена в стандартный каталог tools/venv, исключаемый штатным сканером сторонних библиотек; правила доступа и allowlist не ослаблялись.

Входящие изменения реестра и корпуса сохранены локальными recovery-коммитами, содержимое научных данных не сбрасывалось. Проверка импорта при холодном Python-кеше ошибочно учитывала байткод: воспроизведены записи из importlib._bootstrap_external._cache_bytecode/set_data; с -B записей нет. В изолированную команду теста добавлен -B, поскольку -I игнорирует PYTHONDONTWRITEBYTECODE. Пять первоначально неуспешных проверок прошли повторно; отдельно повторно проверена исправленная команда импорта. Полный 21-минутный набор после этого повторно не запускался; физический код не изменялся.
