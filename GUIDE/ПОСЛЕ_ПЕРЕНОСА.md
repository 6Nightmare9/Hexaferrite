# Где теперь работать

Рабочая папка на этом ноутбуке: **C:\MIPT\working_stuff\Hexaferrite**.

1. Дважды нажмите **START_HEXW.cmd** в этой папке.
2. Оставьте служебное окно открытым.
3. В браузере откройте **http://127.0.0.1:8765/**.
4. Инструкция для открытия двойным щелчком: **GUIDE → Инструкция_HexW.pdf**.

Сейчас сайт уже запущен из новой папки. Повторный запуск не требуется. После перезагрузки выполните первые три шага.

Проверочный расчёт называется **Co–Zn — независимая установка 27.10.2026**. Он сохранён во вкладке «Результаты». Получены 7,375 / 13,285 / 21,324 ГГц при полях 0 / 0,4 / 0,8 Тл; это прежний теоретический сценарий, точность которого ещё не аттестована.
