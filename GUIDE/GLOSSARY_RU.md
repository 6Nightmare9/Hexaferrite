# Глоссарий

Термины из проекта и руководства `README_RU.md`. Формулы и конвенции — в разделе 4.8 основного руководства.

**α-Fe (калибровка)** — эталон для мёссбауэровских спектров: по спектру металлического железа задаётся шкала скоростей и нуль изомерного сдвига.
Без него изомерные сдвиги образцов не имеют абсолютного смысла. Спектр калибровки должен быть предоставлен вами.

**Аудит (`audit`)** — автоматическая проверка целостности: хэши файлов, дубликаты, защита зон, согласованность реестра, самопроверка изоляции.

**Аудит-хук** — механизм Python, который при `import hexw` перехватывает открытие файлов и подобные операции и отказывает модулям теории
в доступе к лабораторным данным и литературному резерву.

**Ba -> Sr (перенос)** — использование данных по Ba-гексаферритам для оценки Sr-систем. Допустимо только с обоснованием и расширенной неопределённостью.

**Fit (литература для подгонки)** — часть литературы, по которой оцениваются параметры модели (`literature\fit`).

**Holdout (слепой резерв)** — часть литературы, отложенная и закрытая для кода теории, чтобы проверить уже зафиксированную модель.
Находится в `literature_holdout`. Для данных лаборатории слово «слепой» используется в том же смысле: ответы недоступны до фиксации.

**Ретроспективная проверка** — сравнение с данными, которые уже использовались при разработке прежней модели или анализа. Показывает согласие, но
не доказывает предсказательную силу; помечается «ретроспективная» с раскрытием прежнего использования.

**Независимая (слепая) проверка** — сравнение прогноза, зафиксированного до просмотра данных, с данными, никогда не участвовавшими в разработке.

**Фиксация (заморозка) модели** — сохранение версии кода, параметров, корпуса источников, настроек DFT и прогнозов до просмотра проверяемых ответов.
После неё любое изменение создаёт новую версию.

**Калибровка (явная)** — подстройка модели по лабораторным данным; допускается только по явной команде пользователя, создаёт новую версию и лишает данные статуса независимой проверки.

**Реестр** — каталог `registry`: образцы, измерения, их происхождение и статус прежнего использования; под контролем версий.

**Prior use (прежнее использование)** — запись о том, использовалось ли измерение раньше (`used_prior`, `unknown_prior_use`, `no_prior_use_found`).

**SHA-256** — контрольная сумма файла; изменение хотя бы одного байта меняет её.

**ParameterEstimate** — запись об оценке параметра: значение, единицы, происхождение, распределение.

**source_role** — роль источника параметра: `literature_fit`, `literature_holdout`, `dft`, `laboratory_validation`, `legacy_prediction`, `explicit_calibration`.

**W-гексаферрит (W-тип)** — гексагональный феррит с пространственной группой P6₃/mmc, состав SrFe(18-x)A(x)O27 (здесь A = Co, Zn, Mn); кристалл можно представить как чередование
шпинельных (S) и гексагональных (R) блоков.

**Позиции W1...W7** — единая нотация семи позиций переходных металлов в W-фазе (4e, 4f, 6g, 4f, 12k, 4f, 2d). Соответствие нотациям разных авторов — `literature\fit\site_notation.md`.

**Модель Горте́ра (Gorter)** — коллинеарная ферримагнитная схема: часть позиций с моментами «вверх», часть «вниз»; для W-типа позиции W1, W2, W6 антипараллельны остальным.

**Fe2+ / Fe3+** — валентные состояния железа. В простой модели SrFe(18-x)A(x)O27 с двухвалентным A число Fe2+ равно 2 − x (при x ≤ 2).

**Ms** — намагниченность насыщения. **μ0Ms** — она же в теслах.

**K1...K4** — константы магнитокристаллической анизотропии (одноосная первого–третьего порядков и базисная шестого порядка).

**Поле анизотропии μ0H_A** — эффективное поле, удерживающее намагниченность вдоль лёгкой оси; для простого случая μ0H_A = 2K1/Ms.

**Конус лёгкого намагничивания** — состояние, в котором равновесная намагниченность лежит на конусе относительно оси c (а не вдоль неё и не в плоскости).

**Тензор размагничивания N** — характеристика формы образца (след равен 1). Определяет вклад размагничивающего поля в энергию и частоты.

**Макроспин** — приближение: намагниченность зерна считается единым вектором постоянной длины.

**ФМР** — ферромагнитный резонанс: резонансное поглощение СВЧ-излучения при прецессии намагниченности. Положение линии зависит от поля, анизотропии и формы.

**Собственный (естественный) ФМР** — резонанс при нулевом внешнем поле, определяемый только внутренними полями.

**H_res (резонансное поле)** — поле, при котором при заданной частоте наступает резонанс.

**LLG (Ландау–Лифшица–Гильберта)** — уравнение движения намагниченности с затуханием α. В проекте основной метод — линеаризованное LLG вблизи равновесия.

**Смит–Бельерс (Smit–Beljers)** — формула частоты ФМР через вторые производные свободной энергии по углам. Используется как независимая проверка LLG; совпадение на машинной точности.

**Формулы Киттеля** — частные случаи частоты ФМР для простых форм (сфера, эллипсоид, плёнка); в проекте служат тестами.

**α (параметр Гильберта)** — безразмерный коэффициент затухания. Для Sr W-типа в корпусе не найден.

**γ, γ/2π, g** — гиромагнитное отношение (рад/(с·Тл)), оно же, делённое на 2π (Гц/Тл), и g-фактор. Это не одно и то же; в коде они не смешиваются.

**μ0H и B** — приложенное поле в теслах и магнитная индукция внутри материала. Первое не равно второму.

**χ(f, H)** — динамическая магнитная восприимчивость (комплексная): χ′ — дисперсия, χ″ — потери. **μ_r = I + χ** — относительная магнитная проницаемость.

**Конвенция exp(−iωt)** — выбор знака мнимой единицы во временной зависимости; при ней потери положительны (χ″ > 0).

**Внешняя / внутренняя восприимчивость** — отклик на приложенное поле (внешняя, динамическое размагничивание включено) или на поле внутри образца.

**Пассивность** — физическое требование: среда не усиливает сигнал (антиэрмитова часть χ положительно полуопределена). Проверяется для результатов.

**Крамерс–Кронинг** — связь вещественной и мнимой частей отклика. Используется для проверки согласованности χ′ и χ″.

**Поликристалл невзаимодействующих зёрен** — приближение керамики: набор независимых кристаллитов с распределением ориентаций; межзёренные взаимодействия и пористость не учитываются.

**Текстура Марча–Долласа** — распределение ориентаций осей c зёрен с одним параметром r (r = 1 — изотропное).

**FWHM** — ширина линии на половине высоты. **ΔH_pp** — расстояние между экстремумами производной линии.

**Статусы ширины** — `valid`, `left_censored` / `right_censored` / `both_censored`, `multipeak`, `insufficient_resolution`, `no_peak`; см. раздел 4.9 руководства.

**Цензурирование (обрезание) линии** — линия выходит за край окна измерения/расчёта, ширина не определена.

**Монте-Карло неопределённости** — многократный расчёт со случайным выбором параметров из заданных распределений; результат — медиана и интервал.

**DFT** — теория функционала плотности: расчёт электронной структуры из первых принципов. **DFT+U** — вариант с поправкой Хаббарда на локализованные d-электроны.

**U** — параметр Хаббарда (эВ); подбирается/калибруется отдельно (в пилотах U = 4 эВ для Fe).

**SCF** — самосогласованный расчёт; итерации повторяются до сходимости.

**Обменные интегралы J** — константы взаимодействия между спинами позиций; определяют температуру Кюри и магнитную структуру. Оцениваются по энергиям нескольких коллинеарных конфигураций.

**Коллинеарный расчёт** — все спины параллельны или антипараллельны одной оси. **SOC** — спин-орбитальное взаимодействие, источник анизотропии; на ноутбуке расчёт с SOC не посилен.

**Γ-точка / сетка k-точек** — выбор точек зоны Бриллюэна; Γ-только — самый дешёвый и наименее точный вариант.

**MPI** — стандарт параллельных расчётов на нескольких ядрах; в используемой сборке Quantum ESPRESSO под Windows отсутствует.

**Quantum ESPRESSO (QE)** — открытый пакет для DFT. **SSSP / GBRV / PAW / USPP** — наборы и типы псевдопотенциалов.

**WSL2** — подсистема Linux в Windows; для установки нужны права администратора, решено её не ставить.

**CIF / mCIF** — файл кристаллической (магнитной) структуры. **Wyckoff** — обозначение кристаллографической позиции (например 4e, 12k).

**РФА (XRD)** — рентгенофазовый анализ. **Cu Kα** — излучение медного анода. **РЭМ/EDS** — электронная микроскопия с энергодисперсионным анализом состава.

**Мёссбауэровская спектроскопия** — резонансное поглощение гамма-квантов ядрами (здесь Co-57 -> Fe-57); даёт информацию о валентности, позициях Fe и сверхтонких полях.

**Спектральная доля / доля фазы / занятость позиции** — разные величины (часть площади спектра, доля фазы по массе/объёму, доля узлов, занятых атомом); в проекте не отождествляются.

**Номинальный и фактический состав** — заданный при синтезе и реально измеренный; нужны оба.

**OA (open access)** — открытый доступ к тексту статьи.

**Umnik** — название папки пользователя с прежними лабораторными данными и прежними анализами.

**Заглушка (stub)** — команда, которая есть в программе, но пока ничего не выполняет и сообщает об этом.
