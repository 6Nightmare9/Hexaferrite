# HexW: инструкция для пользователя

**Версия для открытия двойным щелчком:** [Инструкция_HexW.pdf](Инструкция_HexW.pdf).

Здесь описано, какие кнопки нажимать и где искать результат. Для обычной работы разбираться в устройстве программы не требуется.

**Вся программа находится в папке `C:\MIPT\working_stuff\Hexx`.**

## Быстрый старт

1. В папке программы дважды нажмите **START_HEXW.cmd**.
2. Откройте в браузере **http://127.0.0.1:8765/**. Если страница уже работает, повторно запускать программу не нужно.
3. Нажмите **«Расчёт» → «Заполнить пример Co–Zn»**. В первый раз оставьте заполненные значения.
4. Нажмите **«Рассчитать» один раз**. Внизу страницы, в блоке **«Задачи»**, дождитесь **«Готово»**.
5. Нажмите **«Открыть результат»**. Появятся таблица и графики.

Готово: первый расчёт выполнен. Для повторного просмотра откройте вкладку **«Результаты»**.

![Заполненный пример Co–Zn](images/CoZn_form.jpg)

*Так выглядит заполненная форма. Для запуска используется отдельная кнопка «Рассчитать» ниже полей.*

## Как запускать и заканчивать работу

После запуска START_HEXW.cmd появляется служебное окно. Ничего вводить в нём не нужно. Оставьте его открытым, пока работаете с программой.

Если программу уже запустил помощник, достаточно открыть её адрес в браузере.

Когда все задачи получили статус **«Готово»**, можно закрыть вкладку. При обычном самостоятельном запуске можно также закрыть открытое вами служебное окно. Закрытие одной вкладки браузера не останавливает работающую программу.

После перезагрузки ноутбука снова выполните первые два пункта быстрого старта. Сохранённые результаты останутся на месте. Интернет для обычного расчёта готовой модели не требуется.

## Что изменить для своего образца

Во вкладке **«Расчёт»** заполните основные поля:

| Что вы хотите задать | Что сделать |
|---|---|
| Состав материала | Введите полную формулу в поле «Формула» |
| Понятное название | В поле «Название расчёта» напишите, например, «Образец №3, комнатная температура» |
| Температуру | Введите значение в K. Например, 25 °C соответствуют 298,15 K |
| Диапазон магнитного поля | Укажите начало, конец и число точек. Поле вводится в Тл |
| Диапазон частот | Укажите начало, конец и число точек. Частота вводится в ГГц |
| Форму и направление | Выберите условия, соответствующие вашей задаче |

**Примеры допустимых формул:**

- `SrCo1Zn1Fe16O27` — пример Co–Zn;
- `SrCo2Fe16O27` — Co₂;
- `SrMn2Fe16O27` — Mn₂;
- `SrMg1Fe17O27` — Mg₁;
- `SrNi1Fe17O27` — Ni₁.

Сейчас программа рассчитана на стронциевые W-гексаферриты с Co, Zn, Mn, Mg и Ni. Полную формулу нового состава лучше сверить с коллегой. Другие металлы или другой тип материала могут потребовать развития модели.

**Что значит «число точек»:** при поле от 0 до 0,8 Тл и трёх точках расчёт выполняется для 0; 0,4; 0,8 Тл. Чем больше точек и вариантов параметров, тем дольше задача.

Для первых опытов оставьте **48 реализаций параметров**. Поля **g** и **α**, а также дополнительные настройки без необходимости не меняйте. В учебном примере они уже заполнены; для реального образца значения нужно согласовать с коллегой.

После изменения условий нажмите **«Рассчитать»** и дождитесь завершения. Каждый запрос сохраняется отдельно; прежние результаты не исчезают.

## Как понять, что расчёт закончился

Блок **«Задачи»** находится внизу страницы и виден на всех вкладках.

| Надпись | Что делать |
|---|---|
| «В очереди» | Дождитесь освобождения программы |
| «Выполняется» | Подождите; программа считает |
| «Рассчитываю точку … из …» | Работа продолжается, показан текущий шаг |
| «Готово» | Нажмите «Открыть результат» |
| «Ошибка» | Прочитайте сообщение и передайте его помощнику или коллеге |
| «Прервано» | Найдите работу в «Результатах» и нажмите «Возобновить», если эта кнопка доступна |

Обычно достаточно нескольких минут. Первый запуск может быть дольше повторного. Пока программа считает, можно пользоваться ноутбуком; не закрывайте служебное окно запуска и не выключайте устройство.

## Где смотреть ответ

После **«Открыть результат»** сначала посмотрите на таблицу:

- **T, K** — температура;
- **μ₀H, Тл** — внешнее магнитное поле;
- **медиана, ГГц** — центральное рассчитанное значение собственной частоты;
- **95% диапазон** — разброс прогноза;
- **48 / 48** — все 48 вариантов параметров дали допустимый ответ.

Ниже находятся график изменения частоты с полем и спектры. У графика частоты синяя линия показывает центральные значения, а полоса около неё — разброс прогноза.

![Таблица и график результата Co–Zn](images/CoZn_result.jpg)

**Важно для использования результата:** это исследовательская расчётная оценка. Точность ФМР до 10% пока не подтверждена. Широкая полоса означает, что прогноз существенно зависит от недостаточно известных параметров. Собственная частота и максимум на спектре поглощения могут различаться.

Для учебного Co–Zn при 300 K получены примерно **7,38 ГГц при 0 Тл; 13,29 ГГц при 0,4 Тл; 21,32 ГГц при 0,8 Тл**. Эти значения помогают узнать сохранённый пример; они не являются измерением вашего образца.

## Как сохранить рисунок или таблицу

Все результаты сохраняются автоматически. Дополнительно нажимать «Сохранить расчёт» не требуется.

1. Откройте нужную работу во вкладке **«Результаты»**.
2. Раскройте **«Таблицы и файлы результата»**.
3. Для рисунка откройте файл с окончанием **.png**. Его можно сохранить обычной командой браузера.
4. Для таблицы откройте файл с окончанием **.csv**. Его можно сохранить и открыть в Excel.

Если Excel поместил всё в одну колонку, используйте **«Данные → Из текста/CSV»** и выберите разделитель **«запятая»**.

Нужные файлы первого примера:

- **fmr_vs_field.png** — рисунок частоты от поля;
- **fmr_vs_field.csv** — таблица к этому рисунку;
- **fmr_spectra.png** — обзор спектров.

Остальные файлы нужны для расширенной работы и проверки воспроизводимости. Для обычного просмотра открывать их не требуется.

## Как найти прежний результат

Откройте **«Результаты»**. Последние работы находятся сверху. Ориентируйтесь на название и дату.

Предыдущие версии обычно скрыты. Чтобы увидеть их, включите **«Показывать предыдущие версии»**. Ничего не удаляется: флажок только меняет список на экране.

Обработанные измерения находятся в отдельном списке на этой же вкладке.

## Как обработать своё измерение

Сначала выполните прогноз для нужного образца. Затем:

1. Откройте **«Проверка модели»**, выберите завершённый прогноз и нажмите **«Зафиксировать этот прогноз»**. Это закрепляет версию расчёта перед просмотром измерений.
2. Перейдите в **«Анализ данных»** и выберите метод: РФА, Мёссбауэр, РЭМ, EDS или ФМР.
3. Вставьте полный путь к исходному файлу. В Проводнике его можно получить через правую кнопку мыши и **«Копировать как путь»**. Кавычки вокруг пути удалять не обязательно.
4. Заполните поля выбранного метода.
5. Нажмите **«Обработать»**, дождитесь **«Готово»** и откройте результат.

| Измерение | Что подготовить заранее |
|---|---|
| РФА | Файл измерения и длину волны |
| Мёссбауэр | Файл спектра; для физических сдвигов и полей — подтверждённую калибровку α-Fe |
| РЭМ | Изображение, его масштаб и область без надписей и масштабной линейки |
| EDS | Количественно обработанную таблицу прибора |
| ФМР | Таблицу с осью и сигналом, единицы оси и указание типа сигнала |

Если калибровки Мёссбауэра пока нет, программа покажет график по каналам. Это ожидаемый результат; физические поля и сдвиги в таком случае не выдаются.

Первое **сравнение измерения с прогнозом** лучше подготовить вместе с коллегой: для него нужен отдельный файл с измеренными значениями и условиями. Простая загрузка кривой выполняет её обработку, но сама по себе ещё не является проверкой точности модели.

## Если что-то пошло не так

| Ситуация | Что сделать |
|---|---|
| Страница не открывается | Запустите START_HEXW.cmd и снова откройте адрес программы |
| При запуске написано, что адрес уже занят | Возможно, программа уже работает. Попробуйте открыть http://127.0.0.1:8765/ |
| После исправлений помощника виден старый экран | Обновите вкладку браузера |
| Расчёт не начинается | Проверьте заполнение полей. Конец диапазона должен быть больше начала, если выбрано несколько точек |
| Возле поля появляется предупреждение | Исправьте это поле; единицы указаны в его названии |
| Всё считается слишком долго | В следующий раз сократите число точек. Для знакомства оставьте пример без изменений |
| Ноутбук выключился во время работы | Запустите программу снова и проверьте «Результаты». Для текущей прерванной работы может быть доступно «Возобновить» |
| Появилась ошибка, смысл которой непонятен | Скопируйте её текст или сделайте снимок экрана и передайте помощнику/коллеге |

## Где что лежит

Открывайте папку **C:\MIPT\working_stuff\Hexx**.

| Что нужно найти | Где находится |
|---|---|
| Запуск программы | START_HEXW.cmd |
| Эта инструкция | GUIDE → USER_GUIDE_HEXW_RU.md |
| Полученные графики и таблицы | runs; удобнее открывать через «Результаты» в программе |
| Сохранённые исходные измерения | vault → lab_validation |
| Статьи и исходные материалы | literature; raw → theory_side |
| Подробное научное описание возможностей и ограничений | GUIDE → MODEL_STATUS_V02_RU.md |

Папки **project, registry, tools, audit** содержат служебные части. Для обычной работы их изменять не нужно.

Чтобы сделать резервную копию, дождитесь завершения задач и скопируйте **всю папку Hexx** на выбранный носитель. При переносе на другой компьютер для первого запуска может потребоваться помощь с настройкой программы. Восстановленная исходная флешка для работы на этом ноутбуке не требуется.

Подробная прежняя инструкция для коллег и разработчиков сохранена отдельно: [техническая инструкция](ARCHIVE/USER_GUIDE_HEXW_RU_technical_2026-10-27.md).
