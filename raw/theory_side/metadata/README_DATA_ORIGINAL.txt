Дата: 25 октября 2026 года

КАК ПЕРЕДАТЬ
1. Передайте коллеге этот ZIP. Внутри есть полный промпт, исходные данные и реестр.
2. Коллега распаковывает архив и прикрепляет файл W_hexaferrites_prompt_AB_theory_v2.md
   к своему агенту либо открывает его в рабочей папке агента.
3. Агенту нужно явно дать доступ к распакованным данным. Если он не умеет читать ZIP,
   передайте распакованную папку или файлы по отдельности.
4. Начальное сообщение можно скопировать:
   «Выполни задание из W_hexaferrites_prompt_AB_theory_v2.md.
   Начни с аудита метаданных и построения модели по литературе и DFT.
   Лабораторные измерения используй для проверки после фиксации прогнозов.
   Автоматическую калибровку по нашим данным не включай.
   Уточни рабочую папку перед сохранением результатов».

СОСТАВ И ПОЛНОТА
В комплект включены локальные копии всех 32 исходных вложений, имена которых
восстановлены по доступной истории проекта:
- 8 исходных дифрактограмм .mdi;
- 8 соответствующих текстовых экспортов;
- 5 мёссбауэровских спектров .spc;
- 3 проекта анализа .mtd;
- исходный Archive.zip с дублями пяти .spc;
- расчётный CSV;
- скрипт W (2).txt;
- методика DOCX;
- 4 графика прежней модели.
Дополнительно включена сохранившаяся Excel-таблица FMR_predictions_main_series.xlsx.

Все 33 файла-источника помещены без изменения байтов. Имена сохранены.
Новые служебные файлы: промпт, этот README, MANIFEST.csv и MANIFEST.json.
Реестр содержит размер, SHA-256, категорию и сведения о дублировании.
Литературные PDF и документы по изготовлению измерительной ячейки не входят
в этот комплект измерений.

КАК ИНТЕРПРЕТИРОВАТЬ ДАННЫЕ
Папки 01 и 02 содержат измерения, папка 03 — прежние проекты их обработки.
Папка 04 содержит расчёты и описание прежней модели. Частоты в этих таблицах
не являются измеренными частотами ФМР. Поле «Мёссбауэр/измерен» не делает
остальные свойства строки экспериментальными.

.mdi и .txt одной дифрактограммы — разные представления одного измерения.
Archive.zip дублирует пять отдельных .spc. Два графика vs_x идентичны.
Они сохранены для полноты исходного комплекта, но не увеличивают выборку.
Автоматически приравнивать одинаковые составы к одному образцу нельзя.

По восстановленному списку вложений отдельные измерения ФМР, магнитометрии,
диэлектрических спектров и РЭМ/EDS в этот архив не включены. Если такие новые
данные есть у коллеги, их следует добавить с паспортами образцов.
Основные импортируемые модули старого скрипта в данном комплекте отсутствуют;
скрипт и методика переданы как материалы для аудита, не как гарантированно
запускаемая полная программа.

ПРИОРИТЕТ МОДЕЛИ
Основная модель строится по статьям и DFT. Проверочные лабораторные ответы
не должны влиять на настройку проверяемой версии.
Анализ измерения (например, Ритвельд или подгонка мёссбауэровского спектра)
допустим для получения экспериментальных оценок. Общая теория от этого
автоматически не меняется.
Калибровка по лабораторным результатам — только по отдельной явной команде.
Известные ранее использованные данные нельзя называть слепым испытанием.

ФОРМАТ ПРОМПТА
Markdown в UTF-8 выбран для прямой передачи агенту: сохраняются структура,
ссылки и формулы LaTeX. Достаточно прикрепить .md и дать команду выполнить
задание. При интерфейсе без загрузки .md файл можно открыть в текстовом
редакторе и целиком вставить его содержимое в сообщение.
