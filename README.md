# HexW — модель W-гексаферритов

Приватный рабочий репозиторий: код, литература, исходные измерения, сохранённые расчёты и инструкции. Снимок от 27 октября 2026 года.

**Исследовательская версия 0.2.0. Независимая точность ФМР ≤10% пока не подтверждена.** Теория и результаты обработки измерений сохранены раздельно; эксперимент не переобучает модель автоматически.

## Запуск на другом компьютере

1. Владелец предоставляет коллеге доступ: **Settings → Collaborators → Add people**. Коллега принимает приглашение под своим аккаунтом GitHub.
2. Установите **Git for Windows с Git LFS** и **Python 3.14 с Python launcher**: https://git-scm.com/download/win и https://www.python.org/downloads/windows/ . Для совместной работы также подходит GitHub Desktop.
3. Клонируйте репозиторий в свою локальную папку. Используйте **clone**, а не «Download ZIP»: большие файлы хранятся через Git LFS.
4. Дважды нажмите **SETUP_HEXW.cmd**. Нужен интернет для файлов и библиотек. Дождитесь `Setup complete`.
5. Дважды нажмите **START_HEXW.cmd**, оставьте служебное окно открытым и перейдите в браузере на http://127.0.0.1:8765/ .
6. Откройте [инструкцию PDF](GUIDE/Инструкция_HexW.pdf). Первый пример: «Заполнить пример Co–Zn» → «Рассчитать».

Клонирование через командную строку:

```powershell
git clone https://github.com/6Nightmare9/Hexaferrite.git
cd Hexaferrite
git lfs pull
```

Установка закреплена файлами `project/requirements-test.txt` и `project/requirements.txt`. Установленные библиотеки, старые окружения и исполняемые файлы Quantum ESPRESSO не включены. Обычный расчёт через сайт не требует Quantum ESPRESSO. Для новых DFT-расчётов его нужно установить отдельно.

## Где что находится

| Папка / файл | Содержание |
|---|---|
| `project/hexw` | Код модели и локального сайта |
| `project/tests`, `project/config` | Проверки, составы и настройки |
| `GUIDE/Инструкция_HexW.pdf` | Простая инструкция |
| `GUIDE/MODEL_STATUS_V02_RU.md` | Возможности, ограничения и результаты проверок |
| `runs/predictions` | Теоретические прогнозы |
| `runs/analysis`, `runs/validation` | Обработка измерений и сравнения |
| `literature`, `literature_holdout`, `lit_search` | Литература и правила её использования |
| `raw`, `vault` | Исходные измерения, прежние материалы и аудит |
| `registry` | Реестр образцов, происхождение данных и фиксация модели |
| `dft_runs`, `dft_feasibility`, `tools/pseudo` | Имеющиеся DFT-входы, выходы и псевдопотенциалы |
| `audit/git_history` | Полная прежняя история трёх репозиториев в проверенных Git bundle |
| `audit/GITHUB_EXPORT_MANIFEST.json` | Контрольные суммы перенесённых файлов и исключения |

Пути `C:\MIPT\working_stuff\Hexx` в старых отчётах относятся к исходному ноутбуку. На новом компьютере используйте **свою клонированную папку**: `START_HEXW.cmd` определяет её автоматически. При новой обработке измерения укажите текущий путь к нему; исторические пути в старых результатах не переписаны.

## Совместное редактирование

У каждого своя локальная копия. Для изменения создавайте ветку и отправляйте Pull Request в `main`; коллега просматривает и объединяет правки. См. [CONTRIBUTING.md](CONTRIBUTING.md).

GitHub хранит файлы и историю. Сайт и расчёты запускаются на компьютере каждого участника. На исходном ноутбуке для публикации создана отдельная папка `github_export`; дальнейшие совместные правки выполняйте в ней либо в новом clone. Старый рабочий проект не синхронизируется автоматически.

## Ограничения и воспроизводимость

- Реализована исследовательская цепочка Co–Zn → Mn → Mg/Ni. Полное ТЗ A+B ещё не закрыто.
- РФА с CIF даёт предварительную проверку картины, не полный Ритвельд. Общей автоматической карточки образца для всех измерений пока нет.
- Историческая проверочная выборка частично раскрывалась; она не является полностью слепой.
- Фиксация связывает точные байты файлов и версии библиотек, включая Python. При другой среде старые результаты доступны для просмотра, но строгая фиксация/валидация может потребовать нового расчёта. Не переписывайте печати и контрольные суммы для обхода проверки.
- На исходной машине ранее пройдено 988 тестов, 7 пропущены; затем 23 проверки интерфейса и реальный расчёт Co–Zn в браузере. Это история проверок, не гарантия для нового компьютера.
- Статьи сохраняют права правообладателей. Репозиторий приватный; разрешение на публичное распространение корпуса не предполагается.

## Передать работу ИИ-агенту

Передайте ему ссылку на репозиторий и файл [AGENT_START.md](AGENT_START.md). Полный контекст, архитектура, результаты и незавершённые задачи — в [отчёте для ИИ-агента](GUIDE/ОТЧЁТ_ДЛЯ_ИИ_АГЕНТА.md).

Очередь задач и текущий выбранный прогноз у каждого компьютера свои; они не мешают получению общих изменений. Для обновления остановите своё окно HexW, получите Pull в GitHub Desktop (или `git pull --ff-only` и `git lfs pull`) и снова запустите START. Если изменились зависимости, повторите SETUP.
